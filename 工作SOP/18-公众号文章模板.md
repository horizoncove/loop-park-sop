# 18-公众号文章模板

> **版本：** V1.0
> **用途：** 公众号长文撰写前复制填空
> **原则：** 标题决定打开率，开头决定读完率，结尾决定转发率

---

## 一、标准文章结构（2000-3000字）

### 标题（20字以内）
> 公式：人群 + 痛点/利益 + 数字/情绪

**示例：**
- 沣西大学生每月1000块，怎么花才不亏？
- 开学第一站！这个折扣仓比某宝便宜30%
- 在LOOP PARK摆摊的第30天，她月入过万了

---

### 开头 hook（前100字）

**目的：** 让读者往下读

**常用开头公式：**
1. **痛点式**："开学要买一堆东西，钱包空了？"
2. **场景式**："昨天跟室友逛了一下午，腿都走断了，但真的太值了"
3. **数字式**："120个摊位，2000平米，全年只开10个月——这就是沣西最狠的夜市"
4. **悬念式**："你敢信吗？这个98年的小姐姐，在大学旁边摆摊月入过万"

---

### 正文结构（3-5个小标题）

**每个小标题的写法：**
- 观点先行：一句话说清楚这部分讲什么
- 中间展开：3-5个论据/例子
- 结尾小结：一句话总结，引出下一部分

---

### 结尾 CTA

**目的：** 引导互动+行动

**常用结尾：**
- 你开学第一件事是干嘛？评论区聊聊～
- 想去的同学点个在看，我把攻略放后台了
- 关注我们，每周更新沣西大学生吃喝玩乐指南

---

## 二、4种常用文章模板

### 模板1：活动官宣类

**结构：**
```
【开头】活动预告，制造期待感
【第一部分】活动是什么（时间/地点/内容）
【第二部分】有什么好玩的（分点介绍亮点）
【第三部分】有什么福利（优惠/奖品/抽奖）
【第四部分】怎么参加（报名方式/交通指引）
【结尾】呼吁大家约起来
```

---

### 模板2：攻略干货类

**结构：**
```
【开头】痛点引入（"开学要买好多东西，预算不够？"）
【第一部分】总花费对比（超市买 vs 来LOOP PARK买，省了多少）
【第二部分】分品类推荐（文具/日用品/零食/服饰...）
【第三部分】省钱技巧（怎么买最划算）
【第四部分】交通+营业时间
【结尾】收藏起来，开学直接用
```

---

### 模板3：人物故事类

**结构：**
```
【开头】人物悬念（"在LOOP PARK摆摊的第30天，她..."）
【第一部分】她是谁（为什么来摆摊，之前干嘛的）
【第二部分】怎么开始的（第一次出摊的经历）
【第三部分】现在怎么样了（收入/成长/感受）
【第四部分】想对大家说的话
【结尾】你想认识她吗？周末来逛夜市就能找到
```

---

### 模板4：品牌故事类

**结构：**
```
【开头】我们为什么做LOOP PARK（初心）
【第一部分】我们看到了什么问题（大学生消费痛点）
【第二部分】我们想做成什么样（愿景）
【第三部分】现在进展到哪了（已完成的/正在做的）
【第四部分】接下来要做什么（未来计划）
【结尾】邀请大家一起参与/见证
```

## 三、排版规范

### 字体
- 正文：15px，行间距1.75
- 小标题：17px，加粗
- 引用：14px，灰色，左边框

### 颜色
- 品牌色：墨绿色（#2E5D4E）
- 强调色：橙色（#FF6B35）
- 正文：深灰（#333333）

### 配图
- 首图：900×383（公众号封面比例）
- 文中配图：宽度900px
- 每300-500字一张图，不要大段纯文字
