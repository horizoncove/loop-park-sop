# 43-社群活动执行SOP

> **版本：** V1.0
> **用途：** 社群线上活动从策划到复盘的全流程
> **核心原则：** 每周至少1次社群活动，保持活跃

---

## 一、社群活动类型

| 类型 | 频率 | 示例 |
|------|------|------|
| **福利抽奖** | 每周 | 抽免单、送周边 |
| **话题讨论** | 每两周 | "你最爱的夜市美食" |
| **打卡挑战** | 每月 | 连续7天打卡送积分 |
| **线上投票** | 每月 | 下次活动你想玩什么？ |
| **专属团购** | 每月 | 社群专属折扣 |

---

## 二、活动流程

### 阶段1：策划
- [ ] 这次活动目的是什么？（活跃/拉新/转化）
- [ ] 活动规则写清楚了吗？
- [ ] 奖品/福利准备好了吗？
- [ ] 预算多少？

### 阶段2：预热
- [ ] 提前1天发预告
- [ ] 配好看的海报
- [ ] 群里@全体成员
- [ ] 运营带头起哄

### 阶段3：执行
- [ ] 按规则来，不要改规则
- [ ] 及时回复问题
- [ ] 活跃气氛，别冷场
- [ ] 记录参与数据

### 阶段4：复盘
- [ ] 多少人参加？
- [ ] 互动量多少？
- [ ] 转化多少？
- [ ] 下次怎么优化？

## 三、活动话术模板

**预告：**
> 家人们！本周福利来了～ 今晚8点群里抽奖，抽3位送【宝藏星球50元无门槛券】！记得来哦～

**进行中：**
> 还剩最后10分钟！没参与的抓紧啦～ @张三 @李四 已参与

**开奖：**
> 恭喜 @张三 @李四 @王五 中奖！请私信小助手领奖～ 没中的家人们下周还有！

## 四、活动指标

| 指标 | 目标值 |
|------|--------|
| 活动参与率 | ≥20% |
| 活动互动量 | ≥50条消息 |
| 活动转化率 | ≥5% |
| 群活跃度提升 | ≥30% |
