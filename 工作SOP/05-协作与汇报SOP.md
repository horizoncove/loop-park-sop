# [初版·待合并] 05-协作与汇报SOP

> **版本：** V1.0
> **适用范围：** Agent 与用户的协作机制、汇报节奏、决策边界

---

## 一、决策边界

### 1.1 我可以直接做的（不用问你）
- 知识库文档整理、归档、命名
- 内容初稿撰写、格式调整
- 舆情日常监测、小问题直接处理
- SOP/模板/文档的初稿编写
- 素材分类、标签整理
- 飞书知识库同步的执行

### 1.2 需要你确认的
- 对外发布的所有正式内容
- 人设方向、品牌调性的重大调整
- 周边产品的设计稿确认
- 舆情黄色以上级别的应对策略
- 预算相关的决策
- 新合作/新渠道的开启

### 1.3 必须八将议事的
- 品牌重大调整
- 重大危机公关
- 预算重新分配
- 涉及法律/安全的事件

---

## 二、汇报节奏

### 2.1 每日
- **没事不打扰**：日常监测正常，不用汇报
- **有事必报**：黄色以上舆情、紧急事项立刻说

### 2.2 每周一
发送周度汇报，内容包括：
- 上周完成了什么
- 本周计划做什么
- 需要你决策的事项
- 数据概览（内容数据/舆情情况）

### 2.3 每月初
发送月度汇报，内容包括：
- 上月工作总结
- 核心数据复盘
- 本月重点计划
- 需要你支持的资源

---

## 三、沟通方式

### 3.1 你随时可以跟我说的
| 你说 | 我做 |
|------|------|
| "写个XX方案" | 出初稿，放知识库里 |
| "把这个素材整理一下" | 归档到对应分类 |
| "查一下XX文档" | 从知识库找出来 |
| "同步一下飞书" | 跑同步流程 |
| "这个舆情怎么看" | 分析+给建议 |
| "IP出新表情包" | 出文案+设计brief |

### 3.2 我主动找你的时机
- 舆情黄色以上级别
- 重要内容定稿前
- 每周一周报
- 每月初月报
- 遇到需要你拍板的卡点
- 发现知识库有重大问题

---

## 四、工作节奏

### 4.1 日常工作流
```
早上：舆情扫描 → 处理小问题 → 更新记录
上午：内容创作/文档整理
下午：继续执行 → 遇到卡点上报
晚上：整理当天成果 → 归档
```

### 4.2 优先级原则
1. **紧急优先：** 危机公关、紧急活动宣发
2. **重要第二：** 战略文档、品牌建设
3. **常规第三：** 日常内容、素材整理
4. **有空再做：** 优化提升、整理归档

---

## 五、交付标准

每一项工作完成后，交付物必须：
- ✅ 放在正确的目录下
- ✅ 按命名规则命名
- ✅ 有完整的 frontmatter
- ✅ 格式统一、排版清晰
- ✅ 该有的链接、引用都补上
