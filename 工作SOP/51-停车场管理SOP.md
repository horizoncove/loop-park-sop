# 51-停车场管理SOP

> **版本：** V1.0
> **用途：** 街区停车场日常运营管理标准
> **核心原则：** 出入方便，收费透明，安全有序

---

## 一、停车场基本信息

| 项目 | 标准 |
|------|------|
| **位置** | 街区周边配套停车场 |
| **车位数量** | XX个（含新能源车位XX个） |
| **营业时间** | 10:00-24:00 |
| **收费标准** | 前30分钟免费，之后X元/小时 |

---

## 二、日常管理

### 开放前（10:00前）
- [ ] 检查道闸正常
- [ ] 检查监控正常
- [ ] 清理车位上的杂物
- [ ] 确认收费系统正常

### 营业中
- [ ] 引导车辆有序停放
- [ ] 巡逻检查，发现问题及时处理
- [ ] 确保消防通道畅通
- [ ] 处理刮蹭、纠纷等事件

### 闭场后（24:00后）
- [ ] 清场，通知未离场车辆
- [ ] 检查监控录像
- [ ] 锁闭出入口
- [ ] 记录当日数据

---

## 三、收费规则

1. **前30分钟免费**
2. **会员优惠**：黄金会员以上免费2小时
3. **商户优惠**：消费满XX元免2小时
4. **特殊车辆**：警车、消防车、救护车免费
5. **月卡**：XX元/月，限本地商户和住户

---

## 四、突发事件处理

| 事件 | 处理方式 |
|------|---------|
| **道闸坏了** | 手动放行，联系维修 |
| **车辆刮蹭** | 调监控，引导双方协商 |
| **车辆堵路** | 联系车主挪车 |
| **火灾隐患** | 立即疏散，报消防 |
| **车主投诉** | 耐心解释，记录反馈 |

---

| 平均周转率 | 每周 |
| 车位利用率 | 每月 |
| 收费收入 | 每日 |
