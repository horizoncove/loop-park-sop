# 50-夜市招商SOP

> **版本：** V1.0
> **用途：** 夜市摊主招募、筛选、入驻全流程
> **核心原则：** 学生优先，品类不重复，扶持有梦想的创业者

---

## 一、招募渠道

| 渠道 | 方式 |
|------|------|
| **校园海报** | 各高校贴海报 |
| **社群转发** | 各高校群、LOOP PARK社群 |
| **小红书/抖音** | 发招募笔记 |
| **老摊主推荐** | 推荐成功奖励 |
| **线下报名点** | 现场设报名处 |

---

## 二、摊主筛选标准

| 标准 | 要求 |
|------|------|
| **身份** | 在校大学生优先 |
| **品类** | 不与现有摊位重复 |
| **产品** | 有特色，价格亲民 |
| **卫生** | 能接受卫生检查 |
| **配合度** | 遵守街区规则 |

---

## 三、铺位分级

| 级别 | 位置 | 租金/抽成 | 要求 |
|------|------|----------|------|
| **S级** | 入口/主通道 | 高租金+抽成 | 有特色，颜值高 |
| **A级** | 次主通道 | 中租金+抽成 | 品类好 |
| **B级** | 边缘位置 | 低租金+抽成 | 学生创业优惠 |
| **C级** | 最里面 | 免租试营业 | 新人扶持 |

---

## 四、入驻流程

1. **报名**：填报名表
2. **筛选**：面试+看样品
3. **签约**：签合同，交押金
4. **培训**：教怎么摆摊、卫生要求
5. **进场**：分配位置，开始营业

---

## 五、汰换机制

- 连续2周营业额垫底 → 降级
- 连续4周垫底 → 淘汰
- 卫生不达标 → 警告→罚款→淘汰
- 优秀摊主 → 升级位置
