# 28-IP周边开发SOP

> **版本：** V1.0
> **用途：** 萝卜IP周边从选品到销售的全流程
> **核心原则：** 先小批量试，卖得好再补货，别压库存

## 二、开发流程

### 阶段1：选品评估
- [ ] 这个产品和IP搭不搭？
- [ ] 目标用户是谁？
- [ ] 成本和毛利算过吗？
- [ ] 首批做多少？（建议50-100个试卖）
- [ ] 有没有类似产品卖得好的参考？

---

### 阶段2：设计打样
- [ ] 出设计稿（用哪个角色？什么动作？）
- [ ] 找供应商打样
- [ ] 看样品，调细节
- [ ] 确认最终版

---

### 阶段3：小批量试卖
- [ ] 首批50-100个
- [ ] 线上+线下同时卖
- [ ] 观察2周销量
- [ ] 卖得好→补货；卖不好→清仓

---

### 阶段4：批量复制
- [ ] 确认卖得好，加单
- [ ] 出新款（不同角色/不同款式）
- [ ] 做组合套装
- [ ] 会员专属款/限定款

---

## 三、销售渠道

| 渠道 | 方式 |
|------|------|
| **线下** | 宝藏星球专区+活动快闪 |
| **线上** | 小红书小店+社群团购 |
| **活动** | 活动限定款，现场发售 |
| **会员** | 积分兑换+会员专属款 |

---

## 四、定价策略

- **引流款**：5-10元，贴纸/明信片，用来拉新
- **主力款**：15-50元，钥匙扣/帆布袋，走量
- **利润款**：99+元，玩偶/卫衣，赚利润

---

## 五、库存管理

- 首批不超过100个，别压货
- 卖得好再补，别一次做太多
- 滞销的打折清，别留着占地方
- 限定款可以稍微多备一点
