# 07-小红书文案模板

> **版本：** V1.0
> **用途：** 小红书笔记发布前复制填空
> **使用方式：** 复制本模板 → 填空 → 审核 → 发布

---

## 一、标准笔记模板（通用）

### 标题（20字以内，带情绪/数字/疑问）
> 公式：人群 + 场景 + 痛点/利益 + 情绪词

**示例：**
- 沣西大学生必看！这个周末新发现的宝藏地方
- 开学采购第一站！比某宝便宜一半的折扣仓
- 同学聚会别再去食堂了！这才是正确打开方式

---

### 正文结构

**【开头 hook】**（前3行必须抓住注意力）
> 用一个场景/痛点/疑问开头，让人想往下看

示例：
> 在沣西上学的姐妹！我不允许你还不知道这个地方！
> 昨天跟室友逛了一下午，腿都走断了，但真的太好逛了！

---

**【中段：内容主体】**
按以下结构展开：
1. **是什么**：一句话介绍这是哪里/干什么的
2. **为什么好**：3个亮点（用emoji标注）
3. **多少钱**：价格/优惠信息
4. **怎么去**：地址/交通/营业时间

示例：
> 📍位置：XX大学城旁边，XX路XX号
> 🕒营业时间：XX:XX-XX:XX
> 💰人均：XX元

**亮点1：** xxx
**亮点2：** xxx
**亮点3：** xxx

---

**【结尾CTA】**
引导互动 + 行动指令

示例：
> 你们开学第一件事是干嘛？评论区聊聊～
> 想去的姐妹扣1，我发你们详细攻略！
> 关注我，持续更新沣西大学生吃喝玩乐好去处～

---

### 标签（5-8个，混合大词+小词）
```
#沣西大学城 #咸阳大学生 #开学季 #大学生日常 #周末去哪儿 #西安周边 #宝藏店铺 #LOOPPARK
```

## 二、不同类型笔记模板

### 类型1：探店/打卡类
**适用：** 新店开业、新场景打卡、宝藏星球探店

**结构：**
1. 开头：发现宝藏店的惊喜感
2. 环境：几张图+氛围描述
3. 商品/体验：重点推荐2-3款
4. 价格：性价比突出
5. 总结：值不值得来，适合什么人

---

### 类型2：活动宣发类
**适用：** 市集、篮球赛、节日活动

**结构：**
1. 开头：活动预告，制造期待感
2. 时间地点：清晰明确
3. 活动内容：有什么好玩的
4. 福利：有什么优惠/奖品
5. 呼吁：约上朋友一起来

---

### 类型3：干货/攻略类
**适用：** 开学采购攻略、聚会攻略、省钱攻略

**结构：**
1. 开头：痛点引入（"开学要买好多东西，预算不够？"）
2. 分点列出：按品类/场景分
3. 每点配价格+购买地点
4. 总结：总花费对比，省了多少钱
5. 收藏引导

---

### 类型4：人物/故事类
**适用：** 摊主故事、Season Face、造星计划

**结构：**
1. 开头：人物悬念（"在LOOP PARK摆摊的第30天，她..."）
2. 人物介绍：是谁，为什么来
3. 故事线：创业/成长过程
4. 互动：想对她说的话
5. 地点：在哪里能找到她

## 三、小红书发布检查清单

发布前逐项检查：
- [ ] 标题有没有包含关键词
- [ ] 前3行能不能抓住注意力
- [ ] 图片有没有9张，有没有首图设计
- [ ] 地址和营业时间对不对
- [ ] 价格信息准确吗
- [ ] 有没有引导互动的结尾
- [ ] 标签5-8个，大小词搭配
- [ ] 有没有违禁词（最/第一/绝对等）
- [ ] 有没有@官方账号
