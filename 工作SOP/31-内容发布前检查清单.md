# 31-内容发布前检查清单

> **版本：** V1.0
> **用途：** 每条内容发布前过一遍，避免低级错误
> **原则：** 宁可慢半小时，也不要发出去再改

---

## 一、通用检查（所有平台必过）

### 文字检查
- [ ] 有没有错别字？
- [ ] 标点符号对吗？
- [ ] 有没有违禁词/极限词？（最/第一/国家级...）
- [ ] 品牌名写对了吗？（LOOP PARK，不是Loop Park/loop park）
- [ ] 地址写对了吗？
- [ ] 时间写对了吗？
- [ ] 价格写对了吗？
- [ ] 有没有敏感词？（政治/宗教/黄赌毒...）

---

### 图片/视频检查
- [ ] 图片清晰吗？（不模糊）
- [ ] 有没有水印？（别人家的水印要去掉）
- [ ] 人物肖像授权了吗？
- [ ] 有没有品牌logo？（加上）
- [ ] 尺寸对吗？（符合平台要求）
- [ ] 视频字幕对吗？（和音频一致）

---

### 链接/跳转检查
- [ ] 链接能打开吗？
- [ ] 链接跳转对吗？
- [ ] 定位加了吗？（一定要加定位）
- [ ] @官方账号了吗？
- [ ] 话题标签加了吗？

---

## 二、小红书专项检查

- [ ] 首图好看吗？（决定点击率）
- [ ] 标题12字以内？
- [ ] 正文分段了吗？（别一大坨）
- [ ] 话题标签5-8个？
- [ ] 地点标签加了吗？
- [ ] 有没有引导互动？（"评论区聊聊"）

---

## 三、抖音专项检查

- [ ] 视频前3秒能抓住人吗？
- [ ] 字幕加了吗？
- [ ] BGM选对了吗？（热门/匹配氛围）
- [ ] 封面选好了吗？
- [ ] 文案写了吗？
- [ ] 话题标签3-5个？
- [ ] 定位加了吗？

---

## 四、公众号专项检查

- [ ] 封面图做了吗？
- [ ] 摘要写了吗？
- [ ] 排版好看吗？（手机端预览过吗）
- [ ] 小标题加了吗？
- [ ] 图片插入了吗？
- [ ] 原创声明开了吗？
- [ ] 文末引导关注了吗？

---

## 五、朋友圈专项检查

- [ ] 图片好看吗？（至少3张）
- [ ] 文案像人话吗？（别太像广告）
- [ ] 一天发了几条？（别超过4条）
- [ ] 有没有定位？

---

## 六、发布时间检查

| 平台 | 最佳发布时间 |
|------|-------------|
| 小红书 | 早10点 / 午12点 / 晚8点 |
| 抖音 | 午12点 / 晚7-9点 |
| 公众号 | 早8点 / 晚9点 |
| 朋友圈 | 早8点 / 午12点 / 晚6点 |
