# 17-夜市日常运营SOP

> **版本：** V1.0
> **用途：** 夜市每天的运营节奏、检查清单、突发事件处理
> **营业时间：** 旺季 16:30-24:00 / 平季 16:30-23:00

---

## 一、每日运营时间线

### 14:00 — 准备阶段

| 时间 | 动作 | 负责人 |
|------|------|--------|
| 14:00 | 值班主管到岗，开早会 | 主管 |
| 14:30 | 保洁打扫公共区域 | 保洁 |
| 15:00 | 检查水电设备 | 工程 |
| 15:30 | 监控/照明测试 | 工程 |
| 16:00 | 所有摊主进场，开始布置 | 摊主+现场 |

### 16:00 — 开市前检查

**现场管理巡检清单：**
- [ ] 所有摊位都到了吗？
- [ ] 每个摊位卫生达标吗？
- [ ] 招牌灯箱都亮了吗？
- [ ] 燃气/用电安全检查了吗？
- [ ] 通道畅通吗？
- [ ] 垃圾点清空了吗？
- [ ] 桌椅摆放整齐吗？
- [ ] 配送员到位了吗？

### 16:30 — 正式开市

| 时间 | 动作 |
|------|------|
| 16:30 | 正式开门迎客 |
| 17:00-19:00 | 晚高峰开始，全员盯现场 |
| 19:00-21:00 | 最高峰，重点盯秩序+配送 |
| 21:00-23:00 | 客流渐少，开始收尾 |
| 23:00-24:00 | 收摊，清场 |

### 24:00 — 收摊阶段

| 时间 | 动作 |
|------|------|
| 23:30 | 提醒摊主准备收摊 |
| 24:00 | 停止营业 |
| 24:00-00:30 | 摊主收摊，保洁打扫 |
| 00:30 | 最后巡检，关灯关电 |
| 00:45 | 值班主管下班 |

## 三、每周运营节奏

### 周一 — 周复盘
- 上周数据统计（客流、销售、投诉）
- 问题清单整理
- 本周计划制定

### 周二-周四 — 日常运营
- 正常营业
- 收集摊主反馈
- 处理日常问题

### 周五-周日 — 高峰冲刺
- 全员到岗
- 增加兼职配送员
- 观察客流，随时调整

## 四、突发事件处理

### 4.1 顾客纠纷
**处理流程：**
1. 第一时间上前，把双方分开
2. 了解情况，倾听双方诉求
3. 能现场解决的当场解决
4. 解决不了的上报主管
5. 事后记录，归档

### 4.2 食品安全投诉
**处理流程：**
1. 第一时间带顾客到安静区域
2. 了解情况，拍照取证
3. 先安抚顾客，承诺24小时内回复
4. 联系摊主核实情况
5. 上报主管，按预案处理
6. 事后复盘，整改

### 4.3 设备故障（停电/停水）
**处理流程：**
1. 立即检查原因
2. 能马上修的马上修
3. 修不好的，临时方案（备用电源/临时水管）
4. 通知摊主和顾客
5. 事后记录，报修

### 4.4 恶劣天气（大雨/大风）
**处理流程：**
1. 收到天气预报提前预警
2. 大雨：检查雨棚是否牢固，准备防滑
3. 大风：提前加固雨棚，必要时提前收摊
4. 雷电：停止户外操作，提醒顾客注意安全
5. 事后检查场地，恢复营业

### 4.5 客流超预期
**处理流程：**
1. 立即增加配送员
2. 开放备用就餐区
3. 分流引导（推荐相对空的摊位）
4. 增加安保维持秩序
5. 事后复盘，优化预案
