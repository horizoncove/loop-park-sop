# 08-活动前检查清单

> **版本：** V1.0
> **用途：** 每次活动前逐项打勾，确保不出纰漏
> **使用方式：** 活动前3天开始检查，按清单逐项确认

---

## 一、T-7天：筹备确认

### 方案确认
- [ ] 活动方案已定稿
- [ ] 预算已审批
- [ ] 负责人已明确
- [ ] 分工表已发给所有人

### 物料准备
- [ ] 主视觉海报已设计
- [ ] 背景板/展架已下单
- [ ] 传单/邀请函已印刷
- [ ] 奖品已采购到位

### 人员
- [ ] 主持人已确定
- [ ] 演出/嘉宾已确认
- [ ] 现场工作人员已通知
- [ ] 志愿者已招募到位

---

## 二、T-3天：宣发启动

### 内容素材
- [ ] 官宣海报已发布
- [ ] 小红书预告已发
- [ ] 抖音短视频已发
- [ ] 社群推送已发
- [ ] 朋友圈文案已准备

### 渠道覆盖
- [ ] 公众号推文已发
- [ ] 校园KOL已对接
- [ ] 校内合伙人已通知
- [ ] 线下海报已张贴

---

## 三、T-1天：现场踩点

### 场地
- [ ] 场地布置方案已确认
- [ ] 电源/音响/灯光已测试
- [ ] 座位/站位规划已完成
- [ ] 入口出口已规划

### 设备
- [ ] 音响麦克风已测试
- [ ] 投影/LED屏已测试
- [ ] 直播设备已测试
- [ ] 备用电池/插线板已准备

### 安全
- [ ] 消防通道畅通
- [ ] 应急出口标识清晰
- [ ] 医疗箱已准备
- [ ] 安保人员已安排

---

## 四、T日：活动当天

### 开场前2小时
- [ ] 全体工作人员到位
- [ ] 场地布置完成
- [ ] 设备最终测试
- [ ] 物料摆放到位

### 开场前1小时
- [ ] 嘉宾/主持人到场
- [ ] 彩排完成
- [ ] 签到台准备就绪
- [ ] 摄影/直播到位

### 活动进行中
- [ ] 流程按时间线走
- [ ] 现场拍照/录像
- [ ] 实时监控人流
- [ ] 突发情况有预案

### 活动结束后
- [ ] 物料回收
- [ ] 场地清理
- [ ] 人员清点
- [ ] 复盘会议安排

---

## 五、T+1天：复盘准备

- [ ] 活动照片/视频整理完
- [ ] 客流数据统计完
- [ ] 销售数据统计完
- [ ] 宣传数据统计完（阅读/互动）
- [ ] 亮点/问题初步总结
- [ ] 复盘会议时间已约

---

## 快速检查（5分钟版）

赶时间的时候，只检查这5项：
1. ✅ 方案定了吗？
2. ✅ 物料有了吗？
3. ✅ 人都通知了吗？
4. ✅ 设备测了吗？
5. ✅ 安全考虑了吗？
