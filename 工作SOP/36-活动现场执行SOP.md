# 36-活动现场执行SOP

> **版本：** V1.0
> **用途：** 活动当天现场执行全流程
> **核心原则：** 提前2小时到，走一遍流程，出问题不慌

---

## 一、活动前2小时（到场）

### 场地检查
- [ ] 场地布置完成了吗？
- [ ] 音响/LED屏/灯光测试了吗？
- [ ] 桌椅/物料摆好了吗？
- [ ] 安全通道畅通吗？

### 人员到位
- [ ] 所有工作人员到齐了吗？
- [ ] 分工明确了吗？
- [ ] 对讲机电量足吗？

### 应急准备
- [ ] 急救包有吗？
- [ ] 灭火器在吗？
- [ ] 下雨天的预案准备好了吗？

---

## 二、活动前1小时（预热）

- [ ] 工作人员穿好工作服
- [ ] 各就各位
- [ ] 最后一次设备测试
- [ ] 签到台/入口布置好
- [ ] 开始放音乐暖场

---

## 三、活动进行中

### 开场
- [ ] 提前10分钟提醒准备开场
- [ ] 主持人到位
- [ ] 暖场音乐停，活动开始

### 进行中
- [ ] 按流程走，不赶进度
- [ ] 注意人流，太挤了疏导
- [ ] 实时拍照/拍视频（内容素材）
- [ ] 突发事件及时处理

### 收尾
- [ ] 活动结束，引导有序离场
- [ ] 感谢语+下次活动预告

---

## 四、活动后（清场）

- [ ] 物料回收清点
- [ ] 场地打扫干净
- [ ] 设备搬回仓库
- [ ] 当天数据统计（人数/销售）
- [ ] 素材整理归档

---

## 五、突发事件处理

| 情况 | 处理方式 |
|------|---------|
| 下雨 | 启动雨棚预案，引导到室内 |
| 设备坏了 | 备用设备顶上，不要冷场 |
| 人太多 | 限流，疏导分流 |
| 有人受伤 | 急救包处理，严重打120 |
| 有人闹事 | 保安上前，不要激化 |
