# 16-夜市开业筹备SOP

> **版本：** V1.0
> **用途：** 夜市从0到1的开业筹备全流程
> **时间线：** T-30天 → T日（开业）
> **原则：** 先试营业再正式开业，小步快跑

---

## 一、T-30天：筹备启动

### 确认场地
- [ ] 场地净尺寸测量确认
- [ ] 摊位分区图定稿（A/B/C/D/E区）
- [ ] 水电点位确认
- [ ] 消防通道确认

### 硬件采购
- [ ] 移动雨棚下单（40个）
- [ ] 快餐桌椅下单（200座）
- [ ] 招牌灯箱下单（120个）
- [ ] 监控+照明+垃圾点方案确认

### 摊主招募
- [ ] 招募文案定稿
- [ ] 发布招募（公众号+社群+线下海报）
- [ ] 报名表上线

---

## 二、T-20天：摊主招募中期

### 摊主筛选
- [ ] 收集报名表
- [ ] 初筛资质（健康证+设备）
- [ ] 线下试吃/考察
- [ ] 确定首批摊主名单

### 供应商对接
- [ ] 雨棚供应商确认交货期
- [ ] 桌椅供应商确认交货期
- [ ] 灯箱供应商确认交货期

### 美团对接
- [ ] 联系美团BD，谈夜市专场扶持
- [ ] 确认入驻流程
- [ ] 确认配送员对接方式

---

## 三、T-15天：签约阶段

### 签约缴费
- [ ] 通知摊主签约
- [ ] 签租赁合同
- [ ] 收押金（2000元/人）
- [ ] 收首月管理费
- [ ] 水电表抄表确认

### 培训准备
- [ ] 制定摊主培训课件
- [ ] 制定美团操作手册
- [ ] 制定安全操作手册

---

## 四、T-10天：硬件进场

### 硬件安装
- [ ] 雨棚搭建
- [ ] 桌椅摆放
- [ ] 灯箱安装
- [ ] 监控+照明安装
- [ ] 垃圾点设置

### 摊主进场准备
- [ ] 摊位分配完成（按业态分区）
- [ ] 摊主进场时间通知
- [ ] 水电接通到每个摊位

---

## 五、T-7天：摊主培训

### 培训内容
| 模块 | 内容 | 时长 |
|------|------|------|
| **规则培训** | 管理规则、违规处理、押金扣除 | 30分钟 |
| **美团操作** | 扫码点餐、接单、退款、评价 | 30分钟 |
| **安全培训** | 燃气安全、用电安全、消防 | 30分钟 |
| **卫生培训** | 卫生标准、垃圾处理、餐具消毒 | 20分钟 |
| **答疑** | 现场提问解答 | 20分钟 |

### 培训后考核
- 现场操作美团系统（每人都要会）
- 安全知识问答
- 签字确认已知悉所有规则

---

## 六、T-3天：试营业准备

### 现场布置
- [ ] 所有摊主进场布置
- [ ] 招牌灯箱安装完成
- [ ] 桌椅摆放到位
- [ ] 公共区域清洁完成

### 系统测试
- [ ] 美团扫码点餐测试
- [ ] 配送员接单测试
- [ ] 支付测试
- [ ] 监控测试

### 人员到位
- [ ] 现场管理到位
- [ ] 保洁到位
- [ ] 安保到位
- [ ] 配送员到位

---

## 七、T日：试营业

### 试营业目标
- 不追求人数，跑通流程
- 发现问题，及时调整
- 邀请种子用户体验

### 试营业流程
| 时间 | 动作 |
|------|------|
| 16:00 | 所有人员到位，最后检查 |
| 16:30 | 正式开门 |
| 17:00-20:00 | 高峰时段，全员盯现场 |
| 20:00-22:00 | 观察客流，收集反馈 |
| 22:00 | 收摊，现场清理 |
| 22:30 | 复盘会（问题清单+改进项） |

### 试营业检查清单
- [ ] 点餐流程顺畅吗？
- [ ] 配送速度够快吗？
- [ ] 卫生达标吗？
- [ ] 排队久吗？
- [ ] 有什么突发问题？

---

## 八、T+3天：正式开业

### 正式开业活动
- 开业仪式（简单，剪彩/揭牌）
- 前3天优惠（全场8折/满减）
- 小红书/抖音集中宣发
- 邀请KOL打卡

### 正式开业检查
- [ ] 所有问题已整改
- [ ] 人员全部到位
- [ ] 物料全部准备好
- [ ] 宣传全部发出去了
- [ ] 应急预案准备好
