# 23-朋友圈文案模板

> **版本：** V1.0
> **用途：** 官方朋友圈+员工朋友圈，直接复制套用
> **原则：** 短、有情绪、不硬广，像朋友分享一样

---

## 一、朋友圈发布节奏

| 时间 | 内容类型 | 条数 |
|------|---------|------|
| **早8点** | 早安问候/今日活动预告 | 1条 |
| **午12点** | 美食/好物推荐 | 1条 |
| **晚6点** | 活动现场/人流实拍 | 1条 |
| **晚9点** | 互动话题/晚安 | 1条 |

**每天最多4条，别刷屏。**

---

## 二、6种常用文案模板

### 模板1：活动预告

**结构：** 钩子 + 时间地点 + 福利 + CTA

**示例：**
```
本周末大事发生！🔥
XX月XX日，LOOP PARK夜市周年庆
前100名到场送小礼品！
还有免费抽奖，百分百中奖！
📍地址：沣西XX路XX号
⏰时间：XX月XX日 16:30
约上室友一起来！👇
```

---

### 模板2：探店/种草

**结构：** 惊喜感 + 亮点 + 价格 + 地址

**示例：**
```
挖到宝了！宝藏星球这个零食也太便宜了吧
同款超市卖XX，这里只要XX
我直接囤了一书包😂
📍位置：LOOP PARK 宝藏星球区
💰人均：20元买一大袋
你们开学也来逛逛！
```

---

### 模板3：现场实拍

**结构：** 感叹 + 现场描述 + 邀请

**示例：**
```
今天夜市也太热闹了吧！
人挤人，120个摊全满了
刚排了20分钟队买到的烧烤，值了！😋
还没来的抓紧，周日最后一天
📍LOOP PARK 夜市
```

---

### 模板4：福利/优惠

**结构：** 福利 + 怎么领 + 限时

**示例：**
```
福利来了！🎁
即日起，凭学生证到夜市
全场烧烤第二份半价！
活动时间：XX月XX日-XX月XX日
数量有限，先到先得～
```

---

### 模板5：互动话题

**结构：** 问题 + 引导评论

**示例：**
```
开学第一个月，你花了多少钱？
评论区晒一下，花最少的我送你100元无门槛券！👇
```

---

### 模板6：节气/节日

**结构：** 节日氛围 + 活动结合

**示例：**
```
立秋啦🍂
秋天的第一顿烧烤，安排上了吗？
LOOP PARK夜市秋日暖食节今晚开启！
120个摊位，热乎的都有
快来贴秋膘～
```

## 三、配图规范

### 图片选择
- 首图：最好看的一张（不要用纯文字图）
- 数量：3-6张，不要9张太多
- 内容：现场实拍 > 官方海报

### 图片类型搭配
- 第1张：氛围感大图（全景/夜景）
- 第2-3张：细节特写（美食/商品）
- 第4-5张：人物/互动
- 最后1张：地址/营业时间

---

## 四、员工朋友圈话术

员工转发官方内容时，加一句自己的话：

**不要直接转发官方文案**，要像自己在分享：

> 官方："夜市周年庆，前100名送礼品！"
> 员工版："我们夜市周年庆啦！刚布置完现场，今晚真的超好看，你们快来！前100名有小礼品～"

**员工朋友圈要求：**
- 每周至少发2条
- 必须配现场图（不能只用官方图）
- 要有自己的语气，别像复制粘贴
