# 29-新员工培训SOP

> **版本：** V1.0
> **用途：** 新员工入职培训全流程
> **核心原则：** 7天上岗，30天独立，90天成长

---

## 一、入职第1天

### 上午
- [ ] 签合同/入职手续
- [ ] 领工牌/工作服
- [ ] 认识团队成员
- [ ] 办公环境介绍

### 下午
- [ ] 公司介绍（LOOP PARK是什么、做什么）
- [ ] 组织架构介绍
- [ ] 考勤/请假/报销制度
- [ ] 安全培训（消防/应急）

---

## 二、第1周（岗前培训）

### 第2天：业务认知
- [ ] 项目全貌讲解
- [ ] 各业态介绍（夜市/宝藏星球/自习室/酒馆...）
- [ ] 参观现场

### 第3天：岗位SOP学习
- [ ] 读本岗位SOP文档
- [ ] 跟着老员工看一天
- [ ] 不懂就问

### 第4-5天：实操演练
- [ ] 老员工带着做一遍
- [ ] 自己做，老员工盯着
- [ ] 错了当场纠正

---

## 三、第2周（独立上岗）

- [ ] 独立完成日常工作
- [ ] 每周1次复盘，找问题
- [ ] 继续学其他岗位知识

---

## 四、第1个月（融入期）

- [ ] 完成首次月度复盘
- [ ] 考核：能不能独立干活
- [ ] 不满意的继续带，满意的转正

---

## 五、培训考核标准

| 考核项 | 及格标准 |
|--------|---------|
| 业务知识 | 能说清LOOP PARK是干嘛的 |
| 岗位技能 | 能独立完成日常工作 |
| 服务意识 | 对客户态度好 |
| 安全意识 | 知道应急流程 |
| 团队协作 | 能和同事配合 |
