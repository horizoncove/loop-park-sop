# 21-IP角色详细人设档案

> **版本：** V1.0
> **用途：** 萝卜家族9个角色的完整人设，所有IP内容创作必须符合人设
> **原则：** 人设是冻结的，不能随便改；每个角色有明确的性格、口头禅、内容定位

---

## 二、逐角色详细人设

### 1. 萝卜毛（C位主角）

**基本信息：**
- 名字：萝卜毛
- 年龄：20岁
- 身份：LOOP PARK 官方代言人，大学城新晋网红
- 外形：圆滚滚的小萝卜，头顶一撮毛毛，绿色皮肤，大眼睛

**性格：**
- 热情开朗，见人就打招呼
- 社牛本牛，走到哪聊到哪
- 有点小冒失，但很可爱
- 对一切都充满好奇

**口头禅：**
- "走啊！去逛逛！"
- "这里好好玩！"
- "我请客！（虽然只有一根萝卜）"

**内容定位：**
- 活动主持、开场热场
- 搞笑日常、踩坑记录
- 官方宣布的第一发言人

**适合内容：**
- 活动现场vlog
- 搞笑短剧
- 节日祝福

## 四、内容创作规范

### 人设一致性要求
- 每个角色说话方式要符合人设
- 不能让青哥说一堆话，不能让咪咪变得很man
- 口头禅要常用，但不能每句都用

### 角色出场频率
| 角色 | 出场频率 | 备注 |
|------|---------|------|
| 萝卜毛 | 每周都有 | C位主角 |
| 英宝 | 每周1-2次 | 小红书主力 |
| 大黄 | 每周1-2次 | 夜市/美食主力 |
| 白姐 | 双周1次 | 攻略/干货主力 |
| 咪咪 | 双周1次 | 软萌/美食 |
| 青哥 | 双周1次 | 赛事/运动 |
| 阿呆 | 每月2次 | 电竞/数码 |
| 小白 | 每月1次 | 学习/自习室 |
| 雪人 | 冬季限定 | 12-2月 |
