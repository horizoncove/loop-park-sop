# Cursor 方案包 · 对比用目录

放进「三四份方案一起评」时，Cursor 只交这两份 + 一张可执行表：

| 文件 | 方案 ID | 管什么 |
|---|---|---|
| [方案-Cursor-CANON-V1.md](./方案-Cursor-CANON-V1.md) | `cursor-canon-v1` | 知识库与多 Agent 边界：不搬家，只统一可写源和 ID |
| [方案-Cursor-系统架构-V1.md](./方案-Cursor-系统架构-V1.md) | `cursor-arch-v1` | 现场闭环：面板账本、代码规则、TypeSafe / 豆包参谋、飞书人和手册 |
| [CANON.md](./CANON.md) | — | 开场指针表，不是第四套方案 |

建议对比顺序：先叠 Canon（谁能改、搬不搬家），再叠架构（账本在哪、模型怎么切）。两份共用同一套可写源，不要拆开单评。
