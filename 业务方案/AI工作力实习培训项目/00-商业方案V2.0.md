## 一、为什么这件事现在值得做（V2.0 市场洞察）

### 1.1 一个历史级的类比：AI Agent 之于 2026，就是 Office 之于 2000

> **20 年前，大学教了专业知识，但没教 Office。会 Office 的人，进入任何岗位都抢手。**
> **今天，大学教了专业知识，但没人教 AI Agent。会用 Agent 把专业知识变成交付物的人，是 2026 年的抢手货。**

| 维度 | Office（2000s） | AI Agent（2026） |
|---|---|---|
| 学校教了吗 | 不教 | 不教 |
| 岗位要不要 | 所有岗位要 | 所有岗位要（门槛还在快速抬升） |
| 会的人 | 稀缺 → 抢手 | 稀缺 → 抢手 |
| 差距来源 | 没人教 + 练习机会少 | **token 太贵 + 没人教 + 缺真实任务** |
| 学会后 | 用一辈子 | 持续演进（学的是"学习能力"） |

> 🟢 **结论**：这不是一个"要不要做培训"的问题，是"谁来做这个时代的 Office 培训班"的问题。市场在等一个能用**真实业务场景**教会学生"专业×AI"的地方。

### 1.2 学生的真实困境（我们的目标客户画像）

| 困境 | 具体表现 | 市场现状 |
|---|---|---|
| **token 太贵** | 学生一个月生活费 2000，ChatGPT 订阅 + API 调用一个月能吃掉几百块 | 没有培训机构解决"用不起"的问题 |
| **没人教** | 网上全是通识课（"什么是 AI"），没有"你的专业怎么用 AI 干活"的课 | 通识课免费且泛滥，专业×AI 课稀缺 |
| **缺真实任务** | 学生练手只能做"帮我写个周报"，没有真实业务让他把 Agent 调通、调对、调出质量 | 培训机构没有真实业务，只能模拟 |
| **工具选型混乱** | 学生不知道用哪个工具、怎么配额度、怎么控制成本 | 没有机构把"工具 + 额度 + 成本控制"打包解决 |

> 🔴 **核心判断**：**专业知识不稀缺（学校 4 年教够了），"专业知识 × AI 的交付能力"才稀缺。**
> **我们做的不是 AI 培训，是把"会知识的毕业生"变成"会用 AI 干活的人"。**

### 1.3 我们的独特禀赋（为什么别人抄不走）

| 禀赋 | 具体 | 别人为什么抄不走 |
|---|---|---|
| **① 真实业务场景** | 数据标注公司 + 园区商户 + 3# MCN + 市集 | 绝大多数培训机构没有真实业务，只能模拟 |
| **② 低成本 token 供给** | 豆包/国产模型 + 园区批量额度，**解决"学生用不起"** | 培训机构没有模型供给能力 |
| **③ 专业×AI 师资** | 标注公司骨干、商户老板、MCN 主理人就是"最懂场景的人" | 培训机构只有"AI 讲师"，没有"专业场景讲师" |
| **④ 校园渠道已成体系** | 4 校社群 + KOL + 校内合伙人分销（风将模块） | 招生成本远低于社会机构 |
| **⑤ 6.7 万在校生生源池** | 咸职 2 万 + 陕国贸 2 万 + 交大创新港 2.7 万；邻近陕服、镐京 | 生源现成 |
| **⑥ 身份体系咬合** | 「游客→粉丝→摊主→主理人→创始人」主线 + 「学员→实习生→骨干→创业」支线 | 培训结业学员可成为摊主/主理人候选 |

> 🔴 **必须清醒**：**①②③ 是真正的差异化（别人抄不走），④⑤ 是成本优势，⑥ 是战略价值。V2.0 的课程设计必须围绕 ①②③ 展开。**

### 1.4 一个必须承认的短板（与 V1.0 相同）

**我们不是教育机构。** 园区现有能力栈是商业运营 + 内容 + 校园渠道，没有教学管理、没有课程研发、没有学员管理经验。

> 🟡 **对策（二选一）**：
> - **A. 引进**：外聘有职业教育背景的教务负责人 + 外聘讲师
> - **B. 借力**：与高校/职业培训机构共建，我们提供场景与生源，对方提供教学能力

## 二、产品设计：按"专业 × AI 交付物"排课（V2.0 核心变化）

### 2.1 设计原则（V2.0 强化）

| 原则 | 说明 |
|---|---|
| **从"岗位交付物"倒推"课程"** | 不按工具功能排课，按"这个专业毕业生的岗位每天要交付什么"排课 |
| **专业是教材，AI 是工具** | 学生带着 4 年专业知识来，我们教他把专业知识用 AI 变成交付物 |
| **必须有真实业务任务** | 结业作业 = 真实商户需求 / 真实标注任务 / 真实 MCN 内容 |
| **可验证** | 每个模块有明确交付标准，结业有"能力凭证"（作品集 + 认证） |
| **token 成本内置** | 教学全程用豆包/国产模型 + 园区批量额度，学生不额外花钱 |

### 2.2 课程结构（V2.0 重写：不再是"三层工具课"，而是"专业×AI 交付工作坊"）

```
【第一天 · 诊断日】
  每个学员带着自己的专业和一份"我的专业做什么"进来
  → 用 AI 能力测评，生成个人"专业×AI 差距报告"
  → 明确 4 周后要交付的"结业作品"（真实业务任务）

【第 1-2 周 · 底座搭建】约 30% 课时
  目标：把"会用 AI 干活"变成肌肉记忆
  · 信息检索与事实核查（豆包/深度搜索）
  · 文档生产：纪要、周报、方案、汇报材料（WorkBuddy 流程化）
  · 表格与数据处理：清洗、公式、可视化、报表自动化
  · Agent 入门：把重复劳动变成自动化流程（CodeBuddy）
  · 交付标准：独立完成"给老板看的周报 + 数据表 + 自动化流程演示"

【第 3-4 周 · 专业×AI 主战场】约 50% 课时
  按专业分班，每个班的课程 = 该专业岗位的真实交付物

  ┌─ A 班：商科/会计/电商（对接园区商户 + 标注公司）──────────┐
  │  · 用 AI 做财务对账流水线、经营分析报表                      │
  │  · 电商商品上架、详情页批量生成、客服话术库、销售数据分析    │
  │  · 交付物：真实商户的经营周报 + 电商内容包                   │
  └──────────────────────────────────────────────────────┘
  ┌─ B 班：设计/传媒/艺术（对接 3# MCN + 商户物料需求）────────┐
  │  · AI 出图、改稿、批量生成、风格迁移                        │
  │  · 短视频脚本 + 分镜 + AI 生成 + 账号运营基础               │
  │  · 交付物：真实商户的宣传物料包 + 一个可发布的内容账号      │
  └──────────────────────────────────────────────────────┘
  ┌─ C 班：计算机/数据（对接标注公司 + 园区 OS）───────────────┐
  │  · AI 辅助编程、调 bug、做小工具                            │
  │  · 数据标注评测基础（意图识别、黄金集盲审、RLHF 偏好判断）  │
  │  · 交付物：一个能跑的小工具 + 通过黄金集盲测（一致率≥85%） │
  └──────────────────────────────────────────────────────┘
  ┌─ D 班：文科/法律/管理（对接商户 + 园区运营）───────────────┐
  │  · AI 辅助写作、合同审查、舆情分析、方案撰写                │
  │  · 交付物：真实业务的分析报告 + 方案                         │
  └──────────────────────────────────────────────────────┘

【第 5-6 周 · 真实带岗实战】约 20% 课时
  · 进入标注公司 / 商户 / MCN 的真实岗位，做真实任务 2-4 周
  · 每名学员配一名"业务导师"（商户老板/标注骨干/MCN 主理人）
  · 结业产出：真实实习评价 + 作品集 + 能力认证
```

### 2.3 课时与班型设计（V2.0 调整：取消"速成班"，聚焦主力产品）

| 班型 | 课时 | 周期 | 适合谁 | 定价建议 |
|---|---|---|---|---|
| **专业×AI 认证班**（主力产品） | 84 课时 + 2 周带岗 | **6 周** | 有专业知识的应届/待业毕业生 | 🟢 **5,800–7,800 元** |
| **就业直通班** | 120 课时 + 4 周带岗实习 | **10–12 周** | 明确要入职、愿意多付费 | 🟢 **9,800–15,800 元** |
| **暑期冲刺营**（新增） | 72 课时 | 4 周（暑假） | 大三/大四暑期学生 | 🟢 **3,800–4,800 元** |

> 🔴 **为什么取消速成班**：V1.0 的速成班（1980-2980 元）卖的是"能提效"，但我们的差异化是"专业×AI 交付能力"——速成班撑不起这个卖点，还稀释品牌。V2.0 只保留三档有清晰价值阶梯的产品。

### 2.4 收费结构（保留 V1.0 已验证的设计）

| 机制 | 设计 |
|---|---|
| **分期** | 学费分 2–3 期（开课 / 中期 / 结业），降低首付压力 |
| **退费承诺** | 开课前 3 课时内无条件全额退 |
| **就业奖励返还** | 结业后 3 个月内成功入职对口岗位，返还 20–30% 学费（法律上是奖励而非承诺，避开"包就业"红线） |
| **困难学员减免** | 5–10% 名额减免（作为政策申报的"公益性"证据） |
| **token 供给** | 🟢 **教学期间学员使用豆包/国产模型 + 园区批量额度，不额外收费**（这是"用不起"痛点的直接解法） |

## 三、目标学员与招生策略（V2.0 聚焦）

| 细分 | 特征 | 优先级 |
|---|---|---|
| **A. 本地应届毕业生（未就业）** | 咸阳/西安高校毕业、有专业知识、就业焦虑强、**最典型的"会知识不会用 AI"** | **P0** |
| **B. 已毕业 1–2 年待业青年** | 有工作经历但断续、想转型、专业知识仍在 | **P0** |

| **D. 县域转移劳动力** | 数字化基础弱、无专业知识 | **暂缓**（培训成本高、转化低、最易被"包就业"话术误伤） |

> 🟢 **V2.0 招生主打一句话**：**"你学了 4 年专业知识，现在就差最后一步——会用 AI 把它变成钱。"**

### 3.2 招生渠道（复用园区既有资产 + V2.0 新增）

| 渠道 | 具体 | 成本 |
|---|---|---|

| **高校就业办/就业指导中心** | 与咸职、陕国贸、陕服等对接 | 低 |
| **人社部门渠道** | 就业见习基地 / 职业技能培训补贴 | 低 |

| 🟢 **专业社团定向（新增）** | 会计社团、设计社团、计算机社团——"你的专业×AI"定向课 | 极低（精准） |
| **线上投放** | 抖音/小红书/BOSS 直聘 | 中高（谨慎，广告法监管重点） |

## 四、场地与运营：分两步走（保留 V1.0 已验证设计）

### 4.1 分两步走（V2.0 不改变）

| 阶段 | 场地 | 规模 | 投入 | 前提 |
|---|---|---|---|---|
| **第一步：验证期（0–6 个月）** | 园区现有空间改造（1–2 个教室 + 共享工位） | 20–30 人/班 | 5–15 万元（轻改造） | 必须先跑通一期 |
| **第二步：基地期（6 个月后）** | 独立培训基地 | 100–200 人容量 | 80–200 万元 | 一期就业率与口碑达标 |

> 🔴 **为什么必须分两步**：培训业务现金流形态是"先花钱、后收钱、结果滞后"。基地一旦投下，每月固定成本立刻产生；而招生转化率、完课率、就业率我们现在一个都不知道。**先用 20–30 人跑通完整闭环，用真实数据决定要不要投基地。**

### 4.2 独立基地空间设计（第二步规划）

| 功能区 | 面积占比 | 说明 |
|---|---|---|
| 理论教室（2–3 间） | 25% | 可拼接，支持 30–60 人 |
| **实操工位区** | 40% | 核心——与数据标注公司用工位复用 |
| 项目协作区/讨论室 | 15% | 小组项目 |
| 直播/内容摄制间 | 10% | 对接 B 班与 MCN |
| 就业服务/面试间 | 10% | 面试、洽谈、企业对接 |

> 🟢 **空间关键洞察**：实操工位区与标注业务工位打通，白天培训、项目期上岗，场地利用率翻倍，学员从第一天就在真实业务里。

### 4.3 师资结构（V2.0 强化"业务导师"）

| 角色 | 人数（验证期） | 来源 | 成本 |
|---|---|---|---|
| **教务负责人** | 1 | 必须外聘有职业教育经验的人 | 10,000–15,000 元/月 |
| **AI 工具讲师** | 1–2 | 园区内部 + 外聘 | 8,000–12,000 元/月 |
| **专业方向讲师** | 4（兼职） | 标注公司骨干 / MCN 主理人 / 商户 | 按课时 300–600 元 |
| **业务导师**（V2.0 新增） | 每班 2–3 | 商户老板/标注骨干/MCN 主理人 | 实战期补贴 |
| **就业服务** | 1 | 兼任 | 6,000–8,000 元/月 |
| **班主任/学员管理** | 1 | 兼任 | 5,000–7,000 元/月 |

> 🔴 **最关键的一个人是"教务负责人"**。园区现有团队没有教学管理经验，这个人不能省、不能兼。

>
> **培训业务从"成本中心"变成"园区数字化推进器"——这是 V2.0 相比 V1.0 最值钱的一层价值。**

## 十、一句话总结（V2.0）

> **这个项目的价值不在"培训费"，而在"它第一次把园区的人才池、数据标注业务、市集飞轮和园区 AI 化串成了一条线"。**
>
> 🟢 **V2.0 的正确姿势是"专业 × AI 生产力翻译器"，不是"AI 培训班"**——
> 前者教的是"把你学了 4 年的专业知识，用 AI 变成 2026 年能交付的东西"；后者只是教工具，天花板低、且天然诱导"包就业"宣传。
>
> 🔴 **三个必须守住的底线（不变）**：
> **① 绝不承诺包就业**（合规红线 + 品牌风险）；
> **② 招不满 20–30 人不硬开课**（每期都是净亏）；
> **③ 先跑通一期闭环，再投独立基地**（80–200 万的重资产不能靠想象投）。
>
> 🟢 **以及一个必须抓住的时机（V2.0 新增）**：
> **20 年前的 Office 培训班成就了一代人；2026 年的"专业×AI"培训班，正好轮到我们。**
> **而全沣西，只有我们有真实业务场景 + 低成本 token + 专业场景师资这三张牌。**
