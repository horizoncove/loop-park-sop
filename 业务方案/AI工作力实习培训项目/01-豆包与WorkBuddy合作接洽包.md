## 三、合作接洽函（可直接复制发送）

### 3.1 致豆包/火山引擎（豆包大模型业务咨询表正文）

```
【合作咨询】LOOP PARK 真实工作流 × AI 实训营：寻求 token 供给、讲师派驻与认证合作

您好！我是 LOOP PARK 项目方，想就豆包大模型在职业教育场景的深度合作进行咨询。

【我们是谁】
LOOP PARK 是陕西沣西新城一个覆盖餐饮、零售、住宿、娱乐、内容、电商、社区商业等
非工业类传统行业的青年商业街区（合作方含本地高校，在校生约 5.8 万人）。我们正在
筹建「LOOP AI 工作力实训营」：100 名学员/期，进入园区真实业务部门，用真实数据做
真实工作流——学员交付的不是作业，是部门真正会用的成果。

【为什么找豆包】
1. 学员困于 token 太贵、没人教，AI Agent 使用能力差——需要低成本 token 供给体系；
2. 我们需要官方派驻讲师，负责底座能力课与教学统筹；
3. 我们计划将豆包/火山引擎官方认证纳入结业凭证体系（第二层厂商级认证）。

【我们能提供什么】
1. 真实业务场景（餐饮定价/零售动销/住宿运营/内容分发/标注质检……），是厂商课件
   之外最稀缺的"真实工作流训练场"；
2. 每年数百名付费学员的豆包工具使用与认证考试量；
3. 可复制的"园区 × 厂商 × 培训机构"三方模式案例。

【期望的接洽方向】
- 教学 token 批量额度方案（100-200 元/人/期全包）；
- 派驻讲师合作框架；
- 豆包/火山引擎认证的机构合作与考点备案。

期待与贵方商务/解决方案团队沟通。如需进一步材料（项目介绍、实训营商业方案、
合作条款草案），我们随时可以提供。
联系方式：____________（请回填）
```
