## 执行摘要（一页看懂）

| 维度 | 结论 |
|---|---|
| **做什么** | 面向应届毕业生/待业青年的「专业 × AI」实训营：学员进入园区真实业务部门，用真实数据做真实工作流，AI 是工具、业务是教材 |
| **为什么现在做** | 学生困于 token 太贵、没人教，AI Agent 使用能力很差——就像 20 年前大学生不会用 Office。专业知识不稀缺，"专业知识 × AI 的交付能力"才稀缺 |
| **凭什么我们能做** | ①真实业务场景（别人抄不走）②低成本 token 供给（解决"用不起"）③专业场景师资（部门负责人）④豆包/WorkBuddy 官方派驻讲师 + 认证 |
| **规模与财务** | 100 人/期，单期经常性成本 8.4–16.5 万，收入 63–88.5 万，**单期毛利 46.5–80 万**，一次性投入 8–13 万 1 期收回 |
| **核心壁垒** | 培训机构的"教室教学"教不出真实交付能力；只有有真实业务的园区能 |
| **三条底线** | ①不承诺就业 ②宣传口径过法务 ③先跑通一期 100 人再投基地 |

## 一、市场洞察：为什么这件事值得做

### 1.1 一个历史级的类比

> **20 年前，大学教了专业知识，但没教 Office。会 Office 的人，进入任何岗位都抢手。**
> **今天，大学教了专业知识，但没人教 AI Agent。会用 Agent 把专业知识变成交付物的人，是 2026 年的抢手货。**

| 维度 | Office（2000s） | AI Agent（2026） |
|---|---|---|
| 学校教了吗 | 不教 | 不教 |
| 岗位要不要 | 所有岗位要 | 所有岗位要（门槛还在快速抬升） |
| 会的人 | 稀缺 → 抢手 | 稀缺 → 抢手 |
| 差距来源 | 没人教 + 练习机会少 | **token 太贵 + 没人教 + 缺真实任务** |
| 学会后 | 用一辈子 | 持续演进（学的是"学习能力"） |

**结论**：这不是"要不要做培训"的问题，是"谁来做这个时代的 Office 培训班"的问题。

### 1.2 学生的真实困境

| 困境 | 具体表现 | 市场现状 |
|---|---|---|
| **token 太贵** | 学生月生活费约 2000，AI 订阅+调用一个月能吃掉几百块 | 没有机构解决"用不起" |
| **没人教** | 网上全是通识课（"什么是 AI"），没有"你的专业怎么用 AI 干活"的课 | 专业×AI 课稀缺 |
| **缺真实任务** | 练手只能做"帮我写个周报"，没有真实业务把 Agent 调通调对 | 培训机构没有真实业务 |
| **工具选型混乱** | 不知道用哪个工具、怎么配额度、怎么控成本 | 没有机构打包解决 |

### 1.3 我们的独特禀赋（别人抄不走）

| 禀赋 | 具体 | 为什么抄不走 |
|---|---|---|
| **① 真实业务场景** | 数据标注公司 + 园区商户 + 3# MCN + 市集 | 培训机构没有真实业务，只能模拟 |
| **② 低成本 token 供给** | 豆包/国产模型 + 园区批量额度 | 培训机构没有模型供给能力 |
| **③ 专业×AI 师资** | 部门负责人就是"最懂场景的人" | 培训机构只有"AI 讲师"，没有"场景讲师" |
| **④ 校园渠道已成体系** | 4 校社群 + KOL + 校内合伙人（风将模块） | 招生成本远低于社会机构 |
| **⑤ 生源池现成** | 四校在校生约 5.8 万 | 生源现成 |
| **⑥ 身份体系咬合** | 「游客→粉丝→摊主→主理人→创始人」+「学员→实习生→骨干→创业」 | 结业学员可成为摊主/主理人候选 |

### 1.4 LOOP PARK 恰好是非工业类传统行业的完整切片

| 行业 | 园区对应业务 | 学员能真实接触的工作流 |
|---|---|---|
| **餐饮** | 自营餐饮、夜市、商户餐饮 | 菜单定价、成本核算、堂食/外卖数据、抖音团购运营 |
| **零售** | 宝藏星球 1200 SKU、便利店 | 选品、进货、动销、库存周转、促销 ROI |
| **住宿** | 学生公寓、酒店 | 出租率、定价、淡旺季、保洁排班、线上渠道 |
| **娱乐** | 台球厅、无人小酒馆、KTV、棋牌 | 上座率、分时定价、会员体系、活动拉动 |
| **生活服务** | 自习室、共享空间 | 时段利用率、订阅制、空间运营 |
| **内容/传媒** | 3# MCN、新媒体矩阵、IP 宇宙 | 选题、脚本、拍摄、剪辑、分发、数据复盘 |
| **电商/数字化** | 数据标注公司、园区 OS | 标注任务、数据质量、工具自动化、SaaS 运营 |
| **社区商业** | 市集、活动、招商 | 活动策划、摊位管理、引流、商户服务 |

> 🟢 **一个 LOOP PARK ≈ 一个"非工业类传统行业"的实训基地。学员不是"学行业"，是"在行业里干活"。**

## 二、产品设计：真实工作流实训

### 2.1 设计原则

| 原则 | 说明 |
|---|---|
| **从"岗位交付物"倒推"课程"** | 不按工具功能排课，按"这个专业毕业生岗位每天要交付什么"排课 |
| **专业是教材，AI 是工具** | 学生带着 4 年专业知识来，教他把专业知识用 AI 变成交付物 |
| **必须有真实业务任务** | 结业作业 = 真实商户需求 / 真实标注任务 / 真实 MCN 内容 |
| **可验证** | 每个模块有明确交付标准，结业有"能力凭证" |
| **token 成本内置** | 教学用豆包/国产模型 + 园区批量额度，学生不额外花钱 |

### 2.2 学员的一天（示例：餐饮线）

```
08:30  晨会（部门负责人主持）：今日真实经营数据复盘
09:00  真实任务：用 AI 整理昨日堂食/外卖数据，生成经营日报
10:00  真实任务：用 AI 分析菜单结构，输出 3 个降价/改价建议
11:30  交付给部门负责人 → 当场点评（真实决策采纳或驳回）
14:00  真实任务：为夜市档口做抖音团购文案 × 5
16:00  用 AI 批量生成海报初稿 → 负责人挑选 → 修改
17:30  当日复盘：哪些活被 AI 提效了？卡在哪？怎么调 Agent？
```

> 🟢 **学员交付的不是"作业"，是部门真实会用到的东西。负责人不是"打分"，是"用不用"。**

### 2.3 六大实训线（按部门轮岗 2–3 条 + 主修 1 条）

| 实训线 | 部门 | 学员真实交付物 | 对应专业学员 |
|---|---|---|---|
| **餐饮线** | 自营餐饮/夜市 | 经营日报、定价建议、团购文案、菜单分析 | 商科/经管/市场营销 |
| **零售线** | 宝藏星球/便利店 | 选品分析、动销报表、促销方案、SKU 复盘 | 电商/供应链/商科 |
| **住宿线** | 学生公寓/酒店 | 出租率报表、定价建议、保洁排班优化、渠道运营 | 酒店管理/管理类 |
| **娱乐线** | 台球/小酒馆/KTV | 分时定价方案、会员体系、活动 ROI 分析 | 管理/统计/营销 |
| **内容线** | MCN/新媒体/IP 宇宙 | 选题库、脚本、批量出图、账号数据复盘 | 设计/传媒/中文 |
| **数字化线** | 标注公司/园区 OS | 标注任务评测、数据质检、工具自动化脚本 | 计算机/数据/信息管理 |

### 2.4 评价体系（真实结果说话，不靠考试）

| 评价维度 | 权重 | 依据 |
|---|---|---|
| **真实交付被采纳率** | 40% | 部门负责人是否实际用了学员的产出 |
| **AI 提效能力** | 25% | 同一任务 AI 辅助 vs 手动的耗时差、质量差 |
| **工作流作品集** | 20% | 结业作品集（真实业务成果汇编） |
| **导师综合评价** | 15% | 部门负责人对学员的职业评价 |

> 🟢 **结业凭证 = 作品集 + 部门负责人评价 + 认证。作品集里的每一个条目都是真实业务成果，这是任何培训班都给不了的。**

## 三、师资模型（已定稿）

### 3.1 师资配置

| 角色 | 人数 | 来源 | 成本（6 周/期） |
|---|---|---|---|
| **专职讲师**（底座课 + 教学统筹） | **2 人** | 🟢 **豆包/WorkBuddy 合作派驻** | 🟢 **合作框架内**（预期显著低于外聘） |
| **部门实训导师** | 6–10 人 | **园区各部门负责人（强制带教，计入 KPI）** | 带教补贴 500–1000 元/人/期（≈ 0.5–1 万/期） |
| **教务/班主任** | 1–2 人 | 兼任或园区员工 | 0.8–1.5 万 |
| **合计** | **4–5 人** | — | **≈ 2.5–4.5 万元/期** |

### 3.2 与豆包 / WorkBuddy 的合作框架

| 合作维度 | 设计 | 我们获得 | 合作方获得 |
|---|---|---|---|
| **讲师派驻** | 官方讲师负责底座能力课与教学统筹 | 专业讲师 + 官方认证背书 | 工具装机量、认证考试量、企业客户触达 |
| **认证通道** | 结业学员可考取豆包/WorkBuddy 官方认证 | 结业凭证含金量提升 | 认证体系扩张 |
| **token 供给** | 教学用豆包/国产模型 + 批量额度 | 解决"学生用不起" | 用量与留存 |
| **课程共建** | 官方课程素材与最佳实践 | 底座课质量保证 | 课程分发 |
| **就业协同** | 认证学员进入企业人才库 | 就业出口扩大 | 生态人才供给 |

> 🟢 **官方派驻讲师 = 工具权威 + 认证背书 + 成本下降，三合一。** 工具侧质量由豆包/WorkBuddy 官方背书，业务侧质量由部门 KPI 背书——两头都有质量保证。

### 3.3 部门带教 = KPI 考核（强制机制）

| 机制 | 说明 |
|---|---|
| 🔴 **KPI 考核（强制）** | 带教纳入部门负责人 KPI：带教质量、学员交付采纳率、学员转正数——不达标影响绩效与晋升 |
| 真实产出 | 学员交付物直接解决部门真实问题 |
| 人才储备 | 带得好的学员直接进入部门实习/就业 |
| 绩效激励 | 可设计"学员转正奖金" |

> 🔴 **KPI 设计要点（防"为带教而带教"）**：
> - 带教质量 = 学员匿名评价（≥4.5/5）+ 交付采纳率（≥60%）+ 学员转正数（≥2 人/期）
> - 三项缺一不可；带教不合格的负责人不晋升高管序列
> - 每期由实训营教务 + 园区人事双线考核，防止"自己评自己"

### 3.4 派驻讲师职责

| 职责 | 占比 |
|---|---|
| **底座能力课**（豆包/WorkBuddy 官方工具 + 工作流方法论 + 事实核查 + 成本控制） | 30% 课时 |
| **教学统筹**（课程设计、进度、评价体系、质量门） | 30% |
| **部门实训协调**（学员分组派到各部门，盯交付标准） | 25% |
| **学员管理**（出勤、完课、心理、纠纷） | 15% |

> 🔴 **派驻讲师不是"知识传授者"，是"实训组织者"**——把 100 个学员正确"派发"到真实工作流里，确保每个人在学东西而不是打杂。

## 四、三层权威认证体系（结业凭证）

### 4.1 体系结构

```
第一层：国家级证书（政策背书）
  · 人社部《人工智能训练师》职业技能等级证书（五级~一级）——年满16周岁可报考
  · 人社部《人工智能工程技术人员》专业技术等级（初/中/高级）
  · 人社部教育培训网 AIGC 技术培训证书
  → 全国通用、终身有效、官网可查、可申报政府补贴

第二层：厂商级认证（工具背书）
  · 豆包 / 火山引擎官方认证（含豆包大模型产品等 18 项）
  · WorkBuddy「效率智能体应用师」认证（腾讯云官方机考）
  → 由派驻讲师带考，结业学员直接参加官方考试

第三层：园区实训认证（场景背书）
  · LOOP PARK「真实工作流实训认证」（自建）
  → 作品集 + 部门采纳率 + 导师评价，园区盖章签发
```

### 4.2 认证组合进课程

| 班型 | 结业可获得 | 考试方式 | 附加价值 |
|---|---|---|---|
| **认证班（主力）** | 园区实训认证 + 厂商认证（选考） | 实训采纳率考核 + 官方线上机考 | 厂商认证官网可查 |
| **就业直通班** | 三层全拿：园区实训认证 + 厂商认证 + **人社部证书（选考）** | 实训考核 + 官方机考 + 人社考试 | 国家级证书，求职与补贴双用 |
| **暑期冲刺营** | 园区实训认证 + 厂商认证（选考） | 同上 | 低门槛体验 |

### 4.3 人社部证书抓手

| 证书 | 等级 | 报考门槛 | 对学员的价值 | 对园区的价值 |
|---|---|---|---|---|
| **人工智能训练师**（五级/初级工） | 5 级 | 年满 16 周岁即可报考 | 全国通用、终身有效、官网验真 | 与数据标注业务人才管道直接咬合 |
| **人工智能工程技术人员**（初级） | 3 级 | 需专业背景或培训经历 | 专业技术等级证书 | 可申报"数字技术工程师培育项目" |
| **AIGC 技术培训证书** | 单项 | 参加承办机构培训+考核 | 人社部教育培训网可查 | 对接人社部承办机构体系 |

### 4.4 认证合规边界

| 边界 | 说明 |
|---|---|
| ✅ 可以宣传 | "结业可获得人社部/豆包/WorkBuddy 认证证书"（事实陈述，官网可查） |
| 🔴 不可以 | "包过、保过、100% 拿证"（考试不过写进合同：可免费重考 1 次或退考试费） |
| 🔴 不可以 | "拿证=就业"暗示（证书是能力证明，不是就业承诺） |
| 🟡 需核实 | 人社部证书报考渠道与考点授权（对接陕西省人社厅定点培训机构） |
| 🟡 需核实 | 豆包/WorkBuddy 认证的授权考点/合作培训资质（厂商认证通常要求机构备案） |

## 附：一句话总结

> **本项目最终形态不是培训机构，是"一个用真实业务训练 AI 工作力的实训营"：**
> - **100 个学生，2 名豆包/WorkBuddy 派驻讲师，6–10 个部门负责人带真实业务（带教=KPI）**
> - **学员交付的不是作业，是真实业务成果；评价的不是考试，是采纳率**
> - **结业三层证书：人社部（国家级）+ 豆包/WorkBuddy（厂商级）+ 园区实训认证**
> - **单期毛利 46.5–80 万，一次性投入 1 期收回，就业出口由园区内部消化起步**
>
> 🔴 **三个底线**：**①不承诺就业；②宣传口径过法务；③先跑通一期 100 人再投基地。**
>
> 🟢 **道理**：**培训机构教"知识"，我们训练"干活"。前者卖课时，后者卖能力凭证。而"用真实工作流训练"这件事，恰恰只有有真实业务的园区能做。现在工具权威（豆包/WorkBuddy）、资质（办学许可）、证书（三层认证）全部就位——万事俱备，只欠开班。**
