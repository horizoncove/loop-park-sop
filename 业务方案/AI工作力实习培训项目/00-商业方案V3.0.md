## 〇-B、V3.1 新增确认项（用户已拍板，直接生效）

| # | 确认项 | 决策 | 对方案的影响 |
|---|---|---|---|
| 1 | **办学许可类型** | ✅ **培训机构**（职业技能培训） | 合规口径定为"持证职业技能培训机构"，可申报人社补贴；招生广告标注办学许可证号 |
| 2 | **部门带教机制** | ✅ **必须带教，计入 KPI 考核（强制）** | 实训导师从"激励引导"升级为"制度强制"；带教质量与部门负责人绩效/晋升挂钩 |
| 3 | **专职讲师来源** | ✅ **豆包 / WorkBuddy 合作派驻讲师** | 师资成本结构再次优化（合作方派讲师）；获得官方工具认证背书；认证通道直接打通 |

> 🔴 **V3.1 的三个确认项解决了 V3.0 留下的最大不确定性**：办学许可（合规）、带教意愿（师资地基）、讲师来源（底座课质量）。方案从"需确认"进入"可执行"状态。

> 🔴 **V3.2 的三层认证体系解决了"结业凭证含金量"问题**：国家级（人社部）+ 厂商级（豆包/WorkBuddy）+ 园区级（实训认证），学员付费理由更充分，合规上"标的是认证不是就业"，更安全。

> 🔴 **V3.0 的本质变化**：**我们把"培训机构"从商业模式中删掉了。** 留下的是一套"**真实业务运营 + 学员在真实业务中训练 AI 能力**"的机制。

## 〇-C、V3.2 新增：三层权威认证体系（结业凭证升级）

> 🔴 **核心价值**：V3.1 的结业凭证 = 作品集 + 部门评价 + 认证。V3.2 把"认证"从自封证书升级为**三层真实权威认证**，直接解决两个问题：①结业凭证含金量（学员愿意付费的理由）；②合规安全（标的是"培训+认证"而非"就业"）。

### 三层认证体系

```
┌─────────────────────────────────────────────────────┐
│ 第一层：国家级证书（政策背书）                          │
│  · 人社部《人工智能训练师》职业技能等级证书（五级~一级）   │
│  · 人社部《人工智能工程技术人员》专业技术等级（初/中/高级）│
│  · 人社部教育培训网 AIGC 技术培训证书                    │
│  → 全国通用、终身有效、官网可查、可申报政府补贴            │
├─────────────────────────────────────────────────────┤
│ 第二层：厂商级认证（工具背书）                          │
│  · 豆包 / 火山引擎官方认证（豆包大模型产品等 18 项）       │
│  · WorkBuddy「效率智能体应用师」认证（腾讯云官方机考）     │
│  → 由派驻讲师带考，结业学员直接参加官方考试                │
├─────────────────────────────────────────────────────┤
│ 第三层：园区实训认证（场景背书）                         │
│  · LOOP PARK「真实工作流实训认证」（自建）               │
│  → 作品集 + 部门采纳率 + 导师评价，园区盖章签发           │
└─────────────────────────────────────────────────────┘
```

### 三层认证如何组合进课程（V3.2 设计）

| 班型 | 结业可获得 | 考试方式 | 附加价值 |
|---|---|---|---|
| **认证班（主力）** | 园区实训认证 + 豆包/WorkBuddy 厂商认证（选考） | 实训采纳率考核 + 官方线上机考 | 厂商认证官网可查 |
| **就业直通班** | 三层全拿：园区实训认证 + 厂商认证 + **人社部证书（选考）** | 实训考核 + 官方机考 + 人社考试 | 国家级证书，求职与补贴双用 |
| **暑期冲刺营** | 园区实训认证 + 厂商认证（选考） | 同上 | 低门槛体验 |

### 人社部证书的具体抓手（V3.2 新增）

| 证书 | 等级 | 报考门槛 | 对学员的价值 | 对园区的价值 |
|---|---|---|---|---|
| **人工智能训练师**（五级/初级工） | 5 级，年满 16 周岁即可报考 | 最低门槛、学生可直接考 | 全国通用、终身有效、官网验真 | 与数据标注业务人才管道直接咬合 |
| **人工智能工程技术人员**（初级） | 3 级（初/中/高） | 需专业背景或培训经历 | 专业技术等级证书 | 培训可申报"数字技术工程师培育项目" |
| **AIGC 技术培训证书** | 单项 | 参加承办机构培训+考核 | 人社部教育培训网可查 | 培训可直接对接人社部承办机构体系 |

> 🟢 **V3.2 合规叙事再升级**：**"我们是持证培训机构，结业可获国家级证书（人社部官网可查）+ 厂商级证书（豆包/WorkBuddy 官方）+ 园区实训认证。我们不承诺就业——但证书含金量就是就业力的证明。"**

### 🔴 合规要点（三层认证带来的新边界）

| 边界 | 说明 |
|---|---|
| ✅ 可以宣传 | "结业可获得人社部/豆包/WorkBuddy 认证证书"（事实陈述，官网可查） |
| 🔴 不可以 | "包过、保过、100% 拿证"（考试不过怎么办必须写进合同：可免费重考 1 次或退考试费） |
| 🔴 不可以 | "拿证=就业"暗示（证书是能力证明，不是就业承诺） |
| 🟡 需核实 | 人社部证书报考渠道与考点授权（对接陕西省人社厅定点培训机构） |
| 🟡 需核实 | 豆包/WorkBuddy 认证的**授权考点/合作培训资质**（厂商认证通常要求机构备案） |


## 一、为什么"真实工作流"模式成立（V3.0 核心论证）

### 1.1 学生缺的不是课，是"真实任务"

| 学生现状 | 传统培训班给的 | 我们能给的 |
|---|---|---|
| 学了 4 年专业知识 | 模拟案例题 | **真实商户的经营数据** |
| token 太贵用不起 | 自费 + 免费额度不够 | **园区批量额度全包（100–200 元/人/期）** |
| 没人教怎么用 AI | 工具讲师 | **各部门负责人（每天都在用 AI 处理真实业务的人）** |
| 练手没有场景 | 虚拟项目 | **真实的对账、真实的上新、真实的宣发、真实的活动** |

> 🟢 **一句话**：**学生真正需要的不是"一门 AI 课"，是"一个真实业务的工位 + 一个会 AI 的负责人 + 用不完的 token"。这三样，全沣西只有我们有。**

### 1.2 LOOP PARK 恰好是非工业类传统行业的完整切片

| 行业 | 园区对应业务 | 学员能真实接触的工作流 |
|---|---|---|
| **餐饮** | 自营餐饮、夜市、商户餐饮 | 菜单定价、成本核算、堂食/外卖数据、抖音团购运营 |
| **零售** | 宝藏星球 1200 SKU、便利店 | 选品、进货、动销、库存周转、促销 ROI |
| **住宿** | 学生公寓、酒店 | 出租率、定价、淡旺季、保洁排班、线上渠道 |
| **娱乐** | 台球厅、无人小酒馆、KTV、棋牌 | 上座率、分时定价、会员体系、活动拉动 |
| **生活服务** | 自习室、共享空间 | 时段利用率、订阅制、空间运营 |
| **内容/传媒** | 3# MCN、新媒体矩阵、IP 宇宙 | 选题、脚本、拍摄、剪辑、分发、数据复盘 |
| **电商/数字化** | 数据标注公司、园区 OS | 标注任务、数据质量、工具自动化、SaaS 运营 |
| **社区商业** | 市集、活动、招商 | 活动策划、摊位管理、引流、商户服务 |

> 🟢 **结论**：**一个 LOOP PARK ≈ 一个"非工业类传统行业"的实训基地。学员不是"学行业"，是"在行业里干活"。**

### 1.3 与传统职业教育的本质区别

| 维度 | 传统职教/培训班 | LOOP 实训营 |
|---|---|---|
| 教学主体 | 专职教师 | **部门负责人（业务真实受益者）** |
| 教学内容 | 教材/课件 | **真实经营数据 + 真实决策** |
| 学员产出 | 作业/试卷 | **真实业务成果（直接为园区创造价值）** |
| 评价方式 | 考试 | **业务结果（成交、上座、动销、ROI）** |
| 成本结构 | 教师工资占大头 | **师资边际成本≈0（部门负责人是内部职责）** |

## 二、师资模型（V3.0 核心重构：100 人，2 讲师，部门负责人实训）

### 2.1 师资配置（V3.1 定稿版：豆包/WorkBuddy 派驻讲师 + 部门负责人 KPI 带教）

| 角色 | 人数 | 来源 | 成本（6 周/期） |
|---|---|---|---|
| **专职讲师**（底座课 + 教学统筹） | **2 人** | 🟢 **豆包 / WorkBuddy 合作派驻** | 🟢 **合作框架内**（派驻=合作权益，成本按协议，预期显著低于外聘） |
| **部门实训导师** | 6–10 人 | **园区各部门负责人（强制带教，计入 KPI 考核）** | 带教补贴 500–1000 元/人/期 + KPI 挂钩（≈ 0.5–1 万/期） |
| **教务/班主任** | 1–2 人 | 兼任或园区员工 | 0.8–1.5 万 |
| **合计** | **4–5 人** | — | **≈ 2.5–4.5 万元/期**（讲师成本大幅下降） |

> 🔴 **V3.1 师资成本再降**：V3.0 师资 ≈ 5–7 万/期（讲师外聘），V3.1 因讲师由合作方派驻，单期师资成本预计降至 **2.5–4.5 万**，财务模型进一步改善。

### 2.1-B 与豆包 / WorkBuddy 的合作框架（V3.1 新增）

| 合作维度 | 设计 | 我们获得 | 合作方获得 |
|---|---|---|---|
| **讲师派驻** | 豆包/WorkBuddy 派出官方讲师，负责底座能力课与教学统筹 | 专业讲师 + 官方认证背书 | 工具装机量、认证考试量、企业客户触达 |
| **认证通道** | 结业学员可考取豆包/WorkBuddy 官方认证 | 结业凭证含金量提升（合规：标的是"认证"非"就业"） | 认证体系扩张 |
| **token 供给** | 教学用豆包/国产模型 + 批量额度，官方渠道配给 | "学生用不起"痛点直接解法 | 用量与留存 |
| **课程共建** | 豆包/WorkBuddy 提供官方课程素材与最佳实践 | 底座课质量保证 | 课程分发 |
| **就业协同** | 认证学员进入企业人才库/生态用人需求 | 就业出口扩大 | 生态人才供给 |

> 🟢 **合作的意义远超"省讲师费"**：**官方派驻讲师 = 工具权威 + 认证背书 + 成本下降，三合一。** 这让"专业×AI 实训营"的"AI 侧"有了官方质量担保，我们只需保证"真实业务侧"——而这恰恰是我们的独有能力。

### 2.2 部门负责人为什么愿意带（V3.1 升级：强制机制）

| 机制 | 说明 |
|---|---|
| 🔴 **KPI 考核（强制）** | **带教纳入部门负责人 KPI：带教质量、学员交付采纳率、学员转正数**——不达标影响绩效与晋升 |
| 真实产出 | 学员的交付物直接解决部门真实问题（标注任务、商户物料、活动执行） |
| 人才储备 | 带得好的学员直接进入部门实习/就业（园区自己的用人管道） |
| 绩效激励 | 带教质量计入部门负责人绩效（可设计"学员转正奖金"） |
| 管理能力 | 对负责人自己也是管理训练 |

> 🔴 **KPI 设计要点（避免"为带教而带教"）**：
> - 带教质量 = 学员匿名评价（≥4.5/5）+ 交付采纳率（≥60%）+ 学员转正数（≥2 人/期）
> - 三项缺一不可；带教不合格的负责人不晋升高管序列
> - 每期 KPI 由实训营教务 + 园区人事双线考核，防止"自己评自己"

### 2.3 2 名派驻讲师干什么

| 职责 | 占比 |
|---|---|
| **底座能力课**（豆包/WorkBuddy 官方工具 + 工作流方法论 + 事实核查 + 成本控制） | 30% 课时 |
| **教学统筹**（课程设计、进度、评价体系、质量门） | 30% |
| **部门实训协调**（把学员分组派到各部门，盯交付标准） | 25% |
| **学员管理**（出勤、完课、心理、纠纷） | 15% |

> 🔴 **关键设计**：派驻讲师不是"知识传授者"，是**"实训组织者"**——他们负责把 100 个学员正确地"派发"到真实工作流里，并确保每个学员都在学东西而不是打杂。**工具侧质量由豆包/WorkBuddy 官方背书，业务侧质量由部门 KPI 背书——两头都有质量保证。**

## 三、教学法：真实工作流实训（V3.0 核心）

### 3.1 学员的一天（示例：餐饮线）

```
08:30  晨会（部门负责人主持）：今日真实经营数据复盘
09:00  真实任务：用 AI 整理昨日堂食/外卖数据，生成经营日报
10:00  真实任务：用 AI 分析菜单结构，输出 3 个降价/改价建议
11:30  交付给部门负责人 → 当场点评（真实决策采纳或驳回）
14:00  真实任务：为夜市档口做抖音团购文案 × 5
16:00  用 AI 批量生成海报初稿 → 负责人挑选 → 修改
17:30  当日复盘：哪些活被 AI 提效了？卡在哪？怎么调 Agent？
```

> 🟢 **关键**：学员交付的不是"作业"，是**部门真实会用到的东西**。负责人不是"打分"，是"用不用"。

### 3.2 六大实训线（按部门轮岗 2–3 条 + 主修 1 条）

| 实训线 | 部门 | 学员真实交付物 | 对应专业学员 |
|---|---|---|---|
| **餐饮线** | 自营餐饮/夜市 | 经营日报、定价建议、团购文案、菜单分析 | 商科/经管/市场营销 |
| **零售线** | 宝藏星球/便利店 | 选品分析、动销报表、促销方案、SKU 复盘 | 电商/供应链/商科 |
| **住宿线** | 学生公寓/酒店 | 出租率报表、定价建议、保洁排班优化、渠道运营 | 酒店管理/管理类 |
| **娱乐线** | 台球/小酒馆/KTV | 分时定价方案、会员体系、活动 ROI 分析 | 管理/统计/营销 |
| **内容线** | MCN/新媒体/IP 宇宙 | 选题库、脚本、批量出图、账号数据复盘 | 设计/传媒/中文 |
| **数字化线** | 标注公司/园区 OS | 标注任务评测、数据质检、工具自动化脚本 | 计算机/数据/信息管理 |

### 3.3 评价体系（真实结果说话，不靠考试）

| 评价维度 | 权重 | 依据 |
|---|---|---|
| **真实交付被采纳率** | 40% | 部门负责人是否实际用了学员的产出 |

## 九、一句话总结（V3.1）

> **V2.0 解决了"教什么"（专业×AI），V3.0 解决了"怎么教"（真实工作流）和"谁教"（部门负责人），V3.1 解决了"谁来保证质量"（豆包/WorkBuddy 派驻讲师 + 官方认证）。**
>
> 🟢 **本项目最终形态不是培训机构，是"一个用真实业务训练 AI 工作力的实训营"**：
> - **100 个学生，2 名豆包/WorkBuddy 派驻讲师，6–10 个部门负责人带真实业务（带教=KPI）**
> - **学员交付的不是作业，是真实业务成果；评价的不是考试，是采纳率**
> - **单期毛利 46.5–80 万，一次性投入 1 期收回，就业出口由园区内部消化起步**
> - **办学许可=培训机构已确认，可申报补贴、可公开宣传（但不承诺就业）**
>
> 🔴 **三个底线不变**：**①不承诺就业；②宣传口径过法务（持证但绝不包就业）；③先跑通一期 100 人再投基地。**
>
> 🟢 **一个必须想透的道理**：**培训机构教"知识"，我们训练"干活"。前者卖课时，后者卖能力凭证。而"用真实工作流训练"这件事，恰恰只有有真实业务的园区能做。现在，工具权威（豆包/WorkBuddy）也进来了，资质（办学许可）也解决了——万事俱备，只欠"开班"。**
