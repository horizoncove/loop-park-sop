# 16 广告宣传合规审查清单（含极限词库）

> 适用场景：LoopPark 所有对外宣传物料（海报、公众号、小红书、抖音、KOL种草、活动文案、商铺招牌）
> 法律依据：《广告法》《反不正当竞争法》《消费者权益保护法》《互联网广告管理办法》
> 版本：V1.0 | 生效日期：2026-09-19

---

## 一、广告审查流程

```
业务部门出文案/设计稿
    │
    ▼
法务/合规初审（极限词+虚假宣传）
    │
    ├─ 有问题 → 返回修改
    │
    ▼ 通过
发布前终审（最终版确认）
    │
    ▼
发布后监控（用户投诉/平台审核）
    │
    ▼
问题物料48小时内下架整改
```

## 二、绝对禁用词（极限词库）

### 2.1 国家级/最高级（《广告法》第九条）

| 禁用词 | 说明 |
|--------|------|
| 国家级、世界级、宇宙级 | 不得使用 |
| 最高级、最佳、最好、最大 | 不得使用 |
| 第一、唯一、首个、首选 | 不得使用 |
| 顶级、顶尖、极致、极品 | 不得使用 |
| 全网第一、全国第一 | 不得使用 |
| 销量冠军、市场占有率第一 | 无数据支撑不得使用 |
| 世界级、环球级 | 不得使用 |

### 2.2 虚假/夸大类

| 禁用词 | 说明 |
|--------|------|
| 100%有效、永不反弹 | 不得使用 |
| 包治百病、药到病除 | 不得使用 |
| 零风险、稳赚不赔 | 不得使用（投资/商业宣传） |
| 秒变、立刻见效 | 不得使用（化妆品/美容类） |
| 纯天然、无添加 | 无检测报告不得使用 |

### 2.3 医疗/健康类（食品/化妆品尤其注意）

| 禁用词 | 说明 |
|--------|------|
| 治疗、治愈、疗效 | 普通食品不得宣称医疗功效 |
| 防癌、抗癌、降血压 | 不得使用 |
| 保健、养生 | 普通食品不得宣称保健功能 |
| 减肥、丰胸 | 无特证不得宣称 |

### 2.4 教育/培训类（就业基地注意）

| 禁用词 | 说明 |
|--------|------|
| 包就业、包分配 | 不得使用 |
| 保过、100%通过率 | 不得使用 |
| 名师、名校 | 无资质证明不得使用 |

## 三、LoopPark 业务专项审查

### 3.1 宝藏星球零售宣传

| 检查项 | 标准 |
|--------|------|
| 价格对比 | 不得虚构原价，"原价"需有真实销售记录 |
| 折扣力度 | "打X折"需真实，不得先涨后降 |
| 进口商品 | 标注"进口"需有报关单 |
| 临期食品 | 必须标注"临期食品"及到期日 |
| 赠品 | 必须标注品名、数量、规格 |

### 3.2 培育钻宣传（P0重点）

| 检查项 | 标准 |
|--------|------|
| 产品名称 | **必须标注"培育钻石/实验室钻石"** |
| 话术 | 不得说"真钻""天然钻石""南非钻" |
| 价格对比 | 不得暗示"和天然钻一样" |
| 证书 | 鉴定证书必须明确标注"培育钻石" |

### 3.3 造星计划/KOL种草（P0重点）

| 检查项 | 标准 |
|--------|------|
| 广告标识 | **必须标注"广告"或"合作"** |
| 真实体验 | 不得虚假体验、夸大效果 |
| 粉丝数据 | 不得刷量、买粉 |
| 对比宣传 | 不得贬低同行 |

### 3.4 活动宣传

| 检查项 | 标准 |
|--------|------|
| 抽奖活动 | 最高奖金额不超过5万元 |
| 活动时间 | 明确起止时间，不得虚假宣传 |
| 参与方式 | 规则清晰，无霸王条款 |
| 奖品信息 | 奖品数量、价值明确 |

### 3.5 自营业态宣传

| 业态 | 重点审查 |
|------|----------|
| 无人小酒馆 | 不得宣传"未成年人也能买"，须标注"禁止向未成年人售酒" |
| 自习室 | 不得宣传"保过""学霸聚集地"等 |
| 台球厅/棋牌室 | 不得宣传"赢钱""发财"等涉赌暗示 |

## 四、广告审查自查表

发布前逐项打勾：

- [ ] 无极限词（最高级/第一/唯一等）
- [ ] 无虚假/夸大宣传
- [ ] 价格表述真实（原价有依据）
- [ ] 无医疗/保健功效宣称（食品类）
- [ ] KOL内容标注"广告"
- [ ] 培育钻标注"培育钻石"
- [ ] 抽奖奖品金额≤5万
- [ ] 活动时间/规则明确
- [ ] 无贬低同行
- [ ] 无诱导未成年人消费

## 五、违规后果

| 违规行为 | 处罚 |
|----------|------|
| 使用极限词 | 罚款20-100万 |
| 虚假宣传 | 罚款20-100万，情节严重吊销执照 |
| 无广告标识种草 | 罚款10万以下 |
| 虚假折扣 | 罚款5000-5万 |
| 食品宣称疗效 | 罚款5-20万 |

## 六、注意事项

1. **宁严勿松**：不确定的词一律不用，换更保守的表述。
2. **KOL必审**：达人种草内容发布前必须经法务审核。
3. **保留证据**：所有宣传物料留档，便于应对投诉。
4. **平台规则**：各平台（小红书/抖音）有额外审核规则，需同步遵守。
5. **快速下架**：发现违规物料，48小时内必须下架整改。
