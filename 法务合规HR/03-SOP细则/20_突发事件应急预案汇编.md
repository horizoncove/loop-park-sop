# 20 突发事件应急预案汇编

> 适用场景：LoopPark 全园区突发事件应急处置
> 版本：V1.0 | 生效日期：2026-09-19
> 四大场景：消防 / 食品安全 / 群体事件 / 舆情危机

---

## 一、应急组织架构

```
应急总指挥（项目负责人）
    │
    ├─ 现场指挥（火将）
    ├─ 通讯联络（谣将）
    ├─ 疏散引导（脱将）
    ├─ 医疗救护（脱将兼）
    └─ 对外发言（风将）
```

---

## 二、消防应急预案

### 2.1 报警
- 任何人发现火情立即呼喊
- 按下手动报警按钮
- 拨打119（说清地址：沣西新城康定路×同文路LoopPark）

### 2.2 初期处置
- 小火：就近用灭火器扑灭
- 电器火：先断电再灭火
- 油火：用灭火毯/干粉，不用水

### 2.3 疏散
- 脱将带领按疏散路线撤离
- 不乘电梯
- 到指定集合点清点人数
- 引导消防车入场

---

## 三、食品安全应急预案

### 3.1 疑似食物中毒
1. 立即停止食用可疑食品
2. 封存可疑食品及原料
3. 症状严重者立即送医
4. **2小时内上报沣西新城市场监管局**
5. 提供进货台账和供应商信息

### 3.2 消费投诉食品问题
- 第一时间接待，不争辩
- 记录问题（什么食品/什么时候/什么症状）
- 留样备查
- 及时反馈处理结果

---

## 四、群体事件应急预案

### 4.1 场景
- 客户群体投诉拉横幅
- 商户集体维权
- 活动现场人群拥挤

### 4.2 处置
1. 火将带安保到场维持秩序，不激化矛盾
2. 谣将控制现场信息，不随意表态
3. 引导至独立房间沟通，不影响正常营业
4. 及时上报总指挥
5. 如有人身威胁，立即报警

### 4.3 禁忌
- 不与客户争吵
- 不强行驱赶
- 不随意承诺赔偿

---

## 五、舆情危机应急预案

### 5.1 发现渠道
- 小红书/抖音/微博负面
- 客户投诉升级
- 媒体采访

### 5.2 处置流程
1. 谣将监控舆情，发现后立即上报
2. 2小时内初步了解事实
3. 4小时内拟回应口径
4. 总指挥审批后对外回应
5. 不删评、不硬刚、诚恳回应
6. 持续跟踪舆情走向

### 5.3 回应原则
- 快：24小时内必须回应
- 诚：态度诚恳，不回避问题
- 实：说事实，不说官话
- 改：公布整改措施

## 六、通用应急流程

```
事件发生
    │
    ▼
第一发现人立即上报（10分钟内）
    │
    ▼
现场指挥到场评估（15分钟内）
    │
    ├─ 一般事件 → 现场处理
    └─ 重大事件 → 启动应急预案
    ▼
成立应急小组
    │
    ▼
执行处置方案
    │
    ▼
事件控制
    │
    ▼
事后复盘（5个工作日内）
    │
    ▼
更新预案
```

## 八、注意事项

1. **先救人后救物**：任何情况先保证人的安全
2. **不擅自对外发声**：所有对外信息由风将统一出口
3. **保留证据**：事发后第一时间录像/拍照留存
4. **不隐瞒不拖延**：重大事件必须及时上报，不得瞒报
5. **事后必复盘**：每次事件5个工作日内出复盘报告
