# LoopPark 法务·合规·人力资源 岗位 SOP

> 版本：V1.0 | 生效日期：2026-09-19
> 岗位：法务专员（兼合规负责人 / HR负责人）
> 汇报对象：项目负责人（千门八将之首）
> 适用范围：LoopPark 全业务线

---

## 一、角色定位

### 1.1 三重身份

| 身份 | 核心使命 | 价值主张 |
|------|----------|----------|
| **法务** | 防控法律风险，维护公司合法权益 | 让每一笔业务都经得起诉讼检验 |
| **合规** | 确保公司运营符合法律法规与监管要求 | 让公司不被一纸处罚打回原形 |
| **HR** | 搭建组织能力，激活人才梯队 | 让对的人在对的位置上创造价值 |

### 1.2 服务对象
- **对内**：千门八将核心团队、各业态负责人、校内合伙人、KOL/达人
- **对外**：业主方（橙天地）、供应商、租客、监管部门、客户、律师事务所

### 1.3 工作原则
1. **预防优先**：事前审查 > 事中监控 > 事后补救
2. **业务导向**：不做业务的阻碍者，做业务的护航者
3. **闭环管理**：所有风险发现 → 定级 → 整改 → 验收 → 归档
4. **留痕原则**：所有审批、意见、决定均有书面记录
5. **底线思维**：触碰法律红线的业务，一律一票否决

## 二、法务工作 SOP

### 2.1 合同审查流程

```
业务部门发起 → 法务接收（登记台账）→ 形式审查（5分钟）
    ↓ 通过
实质审查（2个工作日）→ 出具审查意见（修改建议+风险提示）
    ↓
业务部门反馈 → 法务复核 → 定稿用印 → 归档
```

**审查分级：**

| 级别 | 合同类型 | 审查时限 | 审查深度 |
|------|----------|----------|----------|
| A级 | 投资/融资/股权转让/重大资产处置 | 5个工作日 | 全面审查+出具法律意见书 |
| B级 | 租赁合同/采购合同/战略合作协议 | 2个工作日 | 条款审查+风险标注 |
| C级 | 标准模板合同（已审定） | 当日 | 仅核对关键参数 |
| D级 | 业务部门自行拟定的简易协议 | 1个工作日 | 红线条款筛查 |

**必查红线（一票否决项）：**
- [ ] 是否有明确的争议解决条款（管辖法院/仲裁机构）
- [ ] 是否约定了违约责任且不对等
- [ ] 是否存在"无限责任""无条件赔偿"等不合理条款
- [ ] 涉及未成年人的业务是否有年龄限制条款
- [ ] 涉及预收款的是否有退款机制和资金存管条款
- [ ] 知识产权归属是否清晰
- [ ] 保密义务是否覆盖核心商业秘密

### 2.2 法律意见书出具流程

```
业务部门/管理层提出需求 → 法务事实确认（1个工作日）
→ 法规检索与案例研究（2-3个工作日）
→ 出具书面法律意见书（含风险等级、建议方案、备选路径）
→ 管理层决策 → 法务跟踪执行
```

**法律意见书必备要素：**
1. 事实背景（经双方确认）
2. 法律分析（适用法规原文+解读）
3. 风险评估（高/中/低 + 潜在后果）
4. 操作建议（至少2个方案，含利弊分析）
5. 结论与免责声明

### 2.3 纠纷应对流程

```
纠纷发生/收到律师函/起诉通知 → 24小时内上报项目负责人
→ 法务紧急评估（证据梳理、时效计算）
→ 制定应对方案（协商/调解/应诉）
→ 外部律师对接（如需）
→ 执行应对 → 结案归档
```

**纠纷分级响应：**

| 级别 | 情形 | 响应时限 | 决策权限 |
|------|------|----------|----------|
| 紧急 | 收到法院传票/公安传唤/税务稽查 | 2小时内 | 项目负责人+法务 |
| 高 | 客户群体投诉/媒体曝光/群体性事件 | 4小时内 | 项目负责人+法务 |
| 中 | 单个客户纠纷/供应商违约/劳动仲裁 | 1个工作日 | 法务主导 |
| 低 | 日常法律咨询/合同条款疑问 | 2个工作日 | 法务自行处理 |

### 2.4 法律函件起草规范

| 函件类型 | 语气要求 | 核心目的 | 审查要点 |
|----------|----------|----------|----------|
| 律师函/催告函 | 强硬但不失礼貌 | 主张权利、中断时效 | 事实清晰、诉求明确、时限合理 |
| 商洽函/沟通函 | 委婉客气 | 推动合作、解决问题 | 态度诚恳、诉求明确、留有台阶 |
| 告知函/声明函 | 正式客观 | 澄清事实、固定证据 | 事实准确、用词严谨、不扩大化 |
| 离职/辞退通知 | 合法合规 | 解除劳动关系 | 符合劳动法、程序完备 |

## 三、合规工作 SOP

### 3.1 业务合规审查流程

**新业务上线前审查（必经流程）：**

```
业务部门提交《新业务合规审查申请表》
→ 法务合规受理（1个工作日内反馈是否受理）
→ 合规审查（3个工作日）：
   - 主体资质要求
   - 行业准入许可
   - 消费者权益保护
   - 数据合规
   - 广告宣传合规
   - 安全生产
→ 出具《合规审查意见书》：
   - 通过：同意上线
   - 有条件通过：限期整改后上线
   - 不通过：说明理由，禁止上线
→ 业务部门按意见整改 → 法务复核 → 上线
```

### 3.2 定期合规巡检

| 巡检类型 | 频率 | 覆盖范围 | 输出物 |
|----------|------|----------|--------|
| 全面合规巡检 | 每季度1次 | 全部业务线+全部证照 | 《季度合规巡检报告》 |
| 专项合规巡检 | 每月1次 | 当月新上线业务/新政策领域 | 《专项合规检查记录》 |
| 证照有效期监控 | 每月1日 | 全部营业执照/许可证/资质证书 | 《证照到期预警表》 |

**巡检清单（每月必查）：**
- [ ] 营业执照经营范围是否覆盖实际业务
- [ ] 食品经营许可证/烟草证等专项许可证是否在有效期内
- [ ] 消防验收/安全检查记录是否齐全
- [ ] 广告宣传物料是否有违规内容（极限词、虚假宣传）
- [ ] 会员协议/隐私政策是否在显著位置公示
- [ ] 预收款是否按规定备案/存管
- [ ] 员工劳动合同/社保是否合规

### 3.3 合规风险分级与上报

| 风险等级 | 定义 | 上报路径 | 处置时限 |
|----------|------|----------|----------|
| **P0（致命）** | 可能导致停业/巨额罚款/刑事责任 | 立即上报项目负责人+创始人 | 24小时内启动应急 |
| **P1（严重）** | 可能导致行政处罚/群体性纠纷 | 当日上报项目负责人 | 3个工作日内出方案 |
| **P2（中等）** | 可能导致民事赔偿/声誉影响 | 周报中汇报 | 2周内整改 |
| **P3（轻微）** | 不影响实质合规的瑕疵 | 月度汇总 | 1月内整改 |

### 3.4 合规培训

| 培训对象 | 频率 | 内容 | 形式 |
|----------|------|------|------|
| 核心团队（千门八将） | 每季度1次 | 最新法规、重大案例、合规红线 | 线下研讨会 |
| 一线员工/店员 | 每月1次 | 岗位合规要点、消防/食品安全、消费者权益 | 班前会/线上 |
| 校内合伙人 | 每季度1次 | 用工合规、食品安全、宣传规范 | 线上+线下 |
| 新入职员工 | 入职当日 | 合规红线、保密义务、行为规范 | 入职培训 |

## 四、人力资源工作 SOP

### 4.1 招聘入职流程

```
用人部门提出需求 → HR审核编制（确认在预算内）
→ 发布招聘 → 简历筛选 → 初试（HR）
→ 复试（用人部门负责人）→ 终试（项目负责人，仅P0/P1岗位）
→ 发放Offer → 背调（关键岗位）→ 入职报到
→ 入职手续（合同/社保/手册签收）→ 试用期跟踪
```

**招聘分级权限：**

| 岗位级别 | 用人部门 | HR | 项目负责人 |
|----------|----------|-----|------------|
| P0（核心岗/八将） | 初面 | 复面 | 终面 |
| P1（主管/店长） | 初面 | 复面 | 审批 |
| P2（专员/店员） | 初面 | 终面 | 备案 |
| P3（兼职/小时工） | 初面 | 审批 | 备案 |

**入职必办清单（缺一不可）：**
- [ ] 签订劳动合同/劳务协议（按用工类型）
- [ ] 身份证复印件/学历验证
- [ ] 入职登记表
- [ ] 员工手册签收
- [ ] 保密协议（核心岗位）
- [ ] 社保公积金增员（劳动关系员工）
- [ ] 背景调查记录（P0/P1岗位）
- [ ] 入职培训签到表

### 4.2 试用期管理

| 合同期限 | 法定试用期 | 考核节点 |
|----------|------------|----------|
| 3个月~1年 | 不超过1个月 | 入职后第2周、第4周 |
| 1年~3年 | 不超过2个月 | 入职后第1月、第2月 |
| 3年以上/无固定 | 不超过6个月 | 入职后第1/3/6月 |

**试用期考核流程：**
1. 入职第1周：直接上级制定《试用期目标书》，双方签字
2. 试用期过半：中期反馈（书面）
3. 试用期满前7天：员工提交转正申请 + 直接上级评估
4. HR审核 → 项目负责人审批 → 转正/延长/解除

### 4.3 绩效管理

**考核周期：**
- P0/P1岗位：季度OKR + 年度复盘
- P2/P3岗位：月度KPI + 季度汇总
- 兼职/灵活用工：按项目/按班次考核

**考核流程：**
```
目标设定（期初）→ 过程跟踪（月中）→ 自评（期末前3天）
→ 上级评估（期末前2天）→ 绩效面谈（期末后3天内）
→ 结果应用（调薪/奖金/晋升/淘汰）
```

**考核结果应用：**

| 等级 | 比例 | 绩效系数 | 应用 |
|------|------|----------|------|
| S（卓越） | ≤10% | 1.5 | 优先晋升/调薪/年终奖2倍 |
| A（优秀） | ≤20% | 1.2 | 调薪/晋升候选 |
| B（合格） | 60% | 1.0 | 正常发放 |
| C（待改进） | ≤8% | 0.6 | PIP改进计划/调岗 |
| D（不合格） | ≤2% | 0 | 解除合同 |

### 4.4 薪酬福利管理

**薪酬结构（标准模板）：**
```
总薪酬 = 基本工资 + 绩效工资 + 岗位津贴 + 提成/分红 + 福利
```

| 项目 | 发放频率 | 审批权限 |
|------|----------|----------|
| 基本工资 | 月度（次月10日） | HR制表 → 财务复核 → 项目负责人审批 |
| 绩效工资 | 季度 | HR核算 → 部门负责人确认 → 项目负责人审批 |
| 提成/分红 | 按月/按季 | 业务部门核算 → HR复核 → 项目负责人审批 |
| 调薪 | 年度/晋升时 | 部门提出 → HR审核 → 项目负责人审批 |
| 奖金 | 项目结束/年终 | 项目负责人提出 → 创始人审批 |

**薪酬保密原则：**
- 员工薪酬信息仅限HR、直接上级、项目负责人知悉
- 薪酬讨论属违纪行为，入职培训中明确告知

### 4.5 离职管理

**离职类型与流程：**

| 类型 | 发起方 | 流程 | 时限 |
|------|--------|------|------|
| 员工主动辞职 | 员工 | 提交辞职报告 → 工作交接 → 离职面谈 → 出具离职证明 | 提前30天（试用期3天） |
| 协商解除 | 双方 | 提出方案 → 协商一致 → 签署解除协议 → 交接 → 补偿 | 按协商 |
| 过失性辞退 | 公司 | 收集证据 → 工会通知（如有）→ 出具辞退通知 → 交接 | 即时 |
| 非过失性辞退 | 公司 | 提前30天通知/代通知金 → 经济补偿 → 交接 | 30天 |
| 合同到期不续 | 公司/员工 | 到期前30天确认 → 交接 → 补偿（如公司不续） | 30天 |

**离职交接清单（HR必查）：**
- [ ] 工作文档/资料移交
- [ ] 公司财物归还（电脑/工牌/钥匙/门卡）
- [ ] 未结款项核算（报销/借款/提成）
- [ ] 竞业限制启动确认（如适用）
- [ ] 保密义务再次告知
- [ ] 离职证明出具
- [ ] 社保公积金减员
- [ ] 离职面谈记录归档

### 4.6 灵活用工管理（LoopPark 重点）

**用工模式对照表：**

| 用工类型 | 合同形式 | 社保 | 适用场景 | 风险等级 |
|----------|----------|------|----------|----------|
| 全日制劳动关系 | 劳动合同 | 必须缴纳 | 核心团队/店长 | 低 |
| 非全日制用工 | 非全日制劳动合同 | 工伤保险 | 兼职店员/保洁 | 低 |
| 劳务关系 | 劳务协议 | 无需 | 临时活动执行/项目外包 | 中 |
| 实习关系 | 实习协议 | 无需（建议商保） | 在校实习生 | 中 |
| 合作/个体户模式 | 合作协议 | 对方自行承担 | 校内合伙人/KOL/达人 | 高 |
| 劳务派遣 | 派遣协议 | 派遣公司缴纳 | 临时性辅助岗位 | 中 |

**灵活用工风控要点：**
1. **避免事实劳动关系**：合作协议中不得出现"考勤管理""固定薪酬""月度固定发放"等劳动关系特征
2. **校内合伙人**：建议注册个体工商户，按合作关系管理，不纳入考勤
3. **KOL/达人**：签署经纪/合作协议，明确知识产权归属、违约条款、竞业限制
4. **实习生**：签署实习协议，购买商业意外险，不得安排高危岗位

## 五、跨部门协作机制

### 5.1 与各业务线的接口

| 业务线 | 法务接口 | 合规接口 | HR接口 |
|--------|----------|----------|--------|
| 宝藏星球（零售） | 采购合同/供应商协议 | 食品/药品/价格合规 | 店员招聘/管理 |
| 自营业态（7个业态） | 经营资质/租赁合同 | 消防/食品安全/涉赌风险 | 店长/员工管理 |
| 造星计划（KOL） | 达人经纪/合作协议 | 广告法/未成年人/直播合规 | 星探/MCN团队 |
| 活动市集 | 活动合同/安保协议 | 大型活动安全许可/报批 | 活动执行/兼职 |
| 千门八将（核心团队） | 劳动合同/股权/期权 | 核心制度合规 | 招聘/绩效/薪酬 |

### 5.2 日常协作节奏

| 会议/机制 | 频率 | 参与人 | 内容 |
|-----------|------|--------|------|
| 八将周会 | 每周 | 八将全员 | 法务/HR/合规周报，重大风险同步 |
| 合规巡检例会 | 每月 | 各业态负责人 | 月度巡检结果通报，整改跟踪 |
| 人力复盘会 | 每月 | 八将+HR | 编制执行/招聘进度/人员异动 |
| 合规专题会 | 按需 | 相关业务线 | 新业务上线前/重大政策变化 |

### 5.3 文件审批流程

**所有对外文件用印前，必须经法务审核：**
1. 业务部门填写《用印申请单》
2. 附文件正文
3. 法务审核并签字
4. 项目负责人审批
5. 用印登记
6. 归档

**用印分级：**

| 文件类型 | 法务审核 | 项目负责人审批 | 创始人审批 |
|----------|----------|----------------|------------|
| A级（重大合同/法律文件） | 必须 | 必须 | 必须 |
| B级（一般合同/协议） | 必须 | 必须 | - |
| C级（日常行政文件） | 抽查 | 必须 | - |

## 七、应急响应 SOP

### 7.1 突发事件分级

| 级别 | 事件类型 | 响应级别 |
|------|----------|----------|
| 红色 | 停业/查封/刑事立案/群体事件/重大安全事故 | 立即启动应急小组 |
| 橙色 | 行政处罚/媒体曝光/劳动仲裁/大额纠纷 | 当日启动专项处理 |
| 黄色 | 单个客户投诉/员工离职纠纷/供应商违约 | 3个工作日内处理 |
| 蓝色 | 日常咨询/轻微违规/流程优化 | 常规处理 |

### 7.2 应急响应流程

```
事件发生 → 第一时间上报（1小时内）
→ 初步评估定级（2小时内）
→ 成立应急小组（红色/橙色事件）
→ 制定应对方案（24小时内）
→ 执行方案
→ 事后复盘（结案后5个工作日内）
→ 完善制度（防止复发）
```

### 7.3 必须立即上报的10种情况
1. 收到法院传票/仲裁通知/律师函
2. 公安/税务/市场监管/消防等部门上门检查
3. 发生人员伤亡/火灾/安全事故
4. 客户群体投诉/拉横幅/网络曝光
5. 核心员工离职/挖角/泄露商业秘密
6. 供应商重大违约/断供
7. 发现重大合规风险（如无证经营/售假）
8. 媒体采访/负面舆情
9. 客户在经营场所内受伤/财物损失
10. 其他可能导致重大损失或声誉影响的事件

## 八、个人工作节奏

### 每日
- 查看待办审批（合同审查、入离职审批）
