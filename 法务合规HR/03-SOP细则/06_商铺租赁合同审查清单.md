# 06 商铺租赁合同审查清单

> 适用对象：LoopPark 与业主方（橙天地二期）的母租赁合同、与入驻商户的租赁合同
> 法律依据：《民法典》合同编、《商品房屋租赁管理办法》
> 版本：V1.0 | 生效日期：2026-09-19

---

## 一、合同主体审查

| 序号 | 审查项 | 检查要点 | 风险等级 |
|------|--------|----------|----------|
| 1.1 | 出租方主体资格 | 出租方是否为产权人？如非产权人，是否有转租授权？ | 高 |
| 1.2 | 产权证明 | 是否提供房产证/不动产权证复印件？ | 高 |
| 1.3 | 出租方授权 | 如为转租，是否有原产权人同意转租的书面文件？ | 高 |
| 1.4 | 承租方资格 | 承租方是否合法成立？是否具备经营资质？ | 中 |
| 1.5 | 签约人权限 | 签约人是否有授权委托书？ | 中 |

## 二、租赁标的审查

| 2.3 | 房屋用途 | 约定用途是否与实际经营一致？（商业/办公/餐饮） | 高 |
| 2.4 | 房屋现状 | 是否有装修、设备、附属设施清单？ | 中 |
| 2.5 | 交付标准 | 交房时的装修标准、水电接入、消防验收状态？ | 高 |
| 2.6 | 房屋瑕疵 | 是否存在抵押、查封、产权纠纷？ | 高 |

## 九、LoopPark 重点关注条款

### 9.1 与业主方母租赁合同（橙天地二期）

| 重点条款 | 必须明确的内容 |
|----------|----------------|
| 租赁范围 | 全部楼栋面积、公共区域使用权 |
| 租赁用途 | 青年商业综合体、餐饮、零售、娱乐、办公等 |
| 租金及递增 | 起始租金、递增比例、免租期 |
| 转租权 | 同意我方向第三方分租/转租全部或部分面积 |
| 装修审批 | 同意我方对房屋进行装修改造 |
| 消防责任 | 出租方负责整体消防验收，我方负责二次装修消防 |
| 物业责任 | 公共区域维护、安保、保洁由出租方负责 |
| 提前解约 | 出租方不得在合作期内单方面解约 |
| 优先续租 | 我方享有优先续租权 |
| 买卖不破租赁 | 房屋转让不影响本合同效力 |

### 9.2 与入驻商户租赁合同

| 重点条款 | 必须明确的内容 |
|----------|----------------|
| 经营范围 | 明确业态范围，避免同业恶性竞争 |
| 品牌授权 | 商户需提供品牌授权书 |
| 装修标准 | 统一外立面、招牌规范 |
| 营业时间 | 统一营业时间要求 |
| 物业管理 | 物业费标准及服务内容 |
| 退出机制 | 商户提前退租的违约金 |
| 优先续约 | 业绩优秀商户优先续约 |
| 合规责任 | 商户自行办理经营所需证照 |

## 十、审查流程

```
收到租赁合同 → 24小时内形式审查（主体、标的、期限）
→ 3个工作日内实质审查（全部条款）
→ 出具审查意见书（标注风险等级）
→ 业务部门与对方协商修改
→ 法务复核修改稿
→ 定稿用印
→ 归档
```

---

## 常见陷阱提示

1. **"按实际建筑面积计算"**：但未约定建筑面积具体数值，后续可能产生争议。
2. **"出租方有权调整租金"**：模糊表述可能导致随意涨租。
3. **"承租方不得转租"**：LoopPark 商业模式依赖分租，必须争取转租权。
4. **"一切装修归出租方所有"**：装修投入大，应约定残值补偿。
5. **"物业费按政府指导价调整"**：无上限调整可能导致成本失控。
6. **"出租方不承担任何责任"**：单方面免责条款可能无效。
