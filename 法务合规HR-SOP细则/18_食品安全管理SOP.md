# 18 食品安全管理SOP（含临期/退换货）

> 适用场景：宝藏星球食品类商品、市集餐饮摊位、无人小酒馆酒品
> 法律依据：《食品安全法》《食品经营许可管理办法》《消费者权益保护法》
> 版本：V1.0 | 生效日期：2026-09-19
> **P0红线：无证经营食品、销售过期食品、销售OTC药品**

---

## 三、临期食品管理（P0）

### 3.1 临期定义

| 保质期长度 | 临期标准 |
|------------|----------|
| 保质期≥1年 | 到期前45天 |
| 保质期6个月-1年 | 到期前30天 |
| 保质期3-6个月 | 到期前15天 |
| 保质期1-3个月 | 到期前7天 |
| 保质期<1个月 | 到期前3天 |

### 3.2 临期处理流程

```
日常巡检发现临期商品
    │
    ▼
移入"临期食品专区"
    │
    ▼
张贴"临期食品"醒目标识（注明到期日）
    │
    ▼
折价促销（标注折扣价）
    │
    ▼
到期前1天仍未售出 → 立即下架
    │
    ▼
登记销毁记录，不得再售
```

### 3.3 临期专区要求
- 独立陈列，与正常商品物理分开
- 醒目标识："临期食品专区"
- 每件商品标注具体到期日
- 不得隐瞒临期事实

---

## 四、过期食品处理

**绝对红线：过期食品一律销毁，不得再售。**

处理流程：
1. 立即下架，移入不合格品区
2. 登记《不合格食品销毁记录表》
3. 监督销毁（粉碎/丢弃，防止回流）
4. 保留销毁记录2年

---

## 五、储存管理

| 食品类型 | 储存要求 |
|----------|----------|
| 常温食品 | 阴凉干燥，离地离墙10cm |
| 冷藏食品 | 0-4℃，每日记录温度 |
| 冷冻食品 | -18℃以下，每日记录温度 |
| 酒类 | 避光、恒温15-20℃ |
| 散装食品 | 防尘防蝇，标注生产日期 |

---

## 六、员工健康管理

- 接触食品员工必须持有效健康证
- 健康证每年体检更新
- 患有痢疾/伤寒/病毒性肝炎等消化道传染病者不得接触食品
- 每日上岗前晨检（发热/腹泻/手部伤口）

---

## 七、退换货制度

### 7.1 消费者退换货
| 情形 | 处理方式 |
|------|----------|
| 食品有质量问题（变质/异味） | 全额退款+赔偿 |
| 临期食品未告知 | 可退换 |
| 已开封但无质量问题 | 一般不退，特殊情况协商 |
| 过期食品 | 立即下架+赔偿+上报 |

### 7.2 供应商退换货
- 临期/滞销食品与供应商协商退换比例
- 质量问题食品全部退回
- 退换货记录留存

---

## 八、市集餐饮摊位管理

| 检查项 | 标准 |
|--------|------|
| 健康证 | 摊主及操作人员必须持健康证 |
| 食材来源 | 索证索票，台账完整 |
| 加工卫生 | 生熟分开，餐具消毒 |
| 防蝇防尘 | 有遮挡设施 |
| 用水 | 符合生活饮用水标准 |
| 垃圾处理 | 当日清理，不堆积 |

---

## 九、食品安全事故应急

```
发生疑似食物中毒
    │
    ▼
立即停止食用，封存可疑食品
    │
    ▼
送医（如有症状）
    │
    ▼
2小时内上报沣西新城市场监管局
    │
    ▼
配合调查，提供进货台账
    │
    ▼
整改+复盘
```

---

## 十、违规后果

| 违规行为 | 处罚 |
|----------|------|
| 无证经营食品 | 没收违法所得+罚款5-10万 |
| 销售过期食品 | 罚款5-10万，情节严重吊销许可证 |
| 未进货查验 | 罚款5000-5万 |
| 发生食品安全事故 | 罚款+吊销许可证+刑事责任 |

---

## 十一、注意事项

1. **OTC药品绝对不能卖**——宝藏星球"考试急救包"里的布洛芬等必须下架。
2. **临期必须明示**——不能假装是正常商品卖。
3. **台账要完整**——出事时进货台账是免责关键证据。
4. **健康证必查**——市集摊主没健康证不得入场。
5. **每日晨检**——员工不舒服就别碰食品。
