# 34 灵活用工风险防控手册

> 适用范围：LoopPark 全部灵活用工场景
> 核心风险：事实劳动关系认定、工伤、税务
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、灵活用工类型与风险等级

| 类型 | 适用场景 | 风险等级 | 防控要点 |
|------|----------|----------|----------|
| 非全日制（小时工） | 店员/活动帮工 | 中 | 签非全日制协议、控制工时 |
| 实习生 | 在校大学生 | 低 | 签实习协议、买意外险 |
| 校内合伙人 | 学生创业合作 | 中 | 签合作协议、非劳动关系 |
| KOL达人 | 内容创作 | 低 | 签合作协议、按劳务报酬 |
| 劳务外包 | 清洁/安保 | 低 | 签外包合同、不直接管理 |

## 二、最大风险：事实劳动关系

### 2.1 什么是事实劳动关系

虽然签的是"合作协议"，但实际管理方式和全日制员工一样，法院会认定为**事实劳动关系**，需要补缴社保、支付双倍工资、经济补偿金。

### 2.2 认定标准

| 认定要素 | 劳动关系特征 | 合作关系特征 |
|----------|--------------|--------------|
| 管理方式 | 固定考勤/打卡 | 不考勤、按结果付费 |
| 工作时间 | 每日固定8小时 | 灵活时间 |
| 报酬方式 | 按月发工资 | 按次/按项目结算 |
| 工具设备 | 公司提供 | 自备工具 |
| 业务归属 | 公司核心业务 | 非核心/辅助业务 |
| 稳定性 | 长期稳定 | 项目制/短期 |

### 2.3 防控措施

| 风险点 | 防控做法 |
|--------|----------|
| 考勤管理 | 合作人员不打卡、不考勤 |
| 固定发薪 | 按项目/按次结算，不叫"工资" |
| 日常管理 | 不纳入员工管理体系 |
| 穿工服 | 合作方穿自己衣服 |
| 坐班制 | 不要求坐班 |
| 员工福利 | 不发节日福利/年假 |

## 三、分类型风险防控

### 3.1 非全日制（小时工）

| 风险点 | 防控措施 |
|--------|----------|
| 工时超标 | 每日≤4小时，每周≤24小时 |
| 社保 | 只缴工伤险 |
| 工资支付 | 15天一结 |
| 试用期 | 不得约定试用期 |

### 3.2 实习生

| 风险点 | 防控措施 |
|--------|----------|
| 身份核实 | 必须是在校生，有学校证明 |
| 工伤 | 买商业意外险（50万保额） |
| 报酬 | 叫"实习补贴"，不叫工资 |
| 工作内容 | 不安排高危/夜班 |

### 3.3 校内合伙人

| 风险点 | 防控措施 |
|--------|----------|
| 合作性质 | 签《合作协议》，明确非劳动关系 |
| 费用结算 | 按销售分成，不发固定工资 |
| 管理方式 | 不考勤、不打卡 |
| 票据 | 要求提供发票（个体户代开） |

### 3.4 KOL达人

| 风险点 | 防控措施 |
|--------|----------|
| 合作性质 | 签《内容创作合作协议》 |
| 费用结算 | 按条/按效果结算 |
| 发票 | 达人提供发票或代扣个税 |
| 著作权 | 明确作品著作权归属 |

## 四、工伤风险防控

### 4.1 灵活用工工伤处理

| 类型 | 工伤责任 | 防控 |
|------|----------|------|
| 非全日制 | 单位承担工伤责任 | 必须缴工伤险 |
| 实习生 | 单位按侵权责任赔偿 | 买商业意外险 |
| 合伙人 | 自行承担 | 合作协议明确各自负责 |
| KOL | 自行承担 | 合作协议明确 |
| 外包 | 外包公司承担 | 合同明确外包公司负责 |

### 4.2 必做的事

1. **非全日制必须缴工伤险**
2. **实习生必须买意外险**
3. **活动帮工必须买短期意外险**（活动前买，活动后到期）
4. **所有合作协议写清楚责任划分**

## 五、税务风险防控

| 用工类型 | 个税处理 | 发票要求 |
|----------|----------|----------|
| 全日制员工 | 工资薪金代扣 | 无需发票 |
| 非全日制 | 工资薪金/劳务报酬 | 无需发票 |
| 实习生 | 劳务报酬代扣 | 可凭收据 |
| 校内合伙人 | 经营所得 | 需代开发票 |
| KOL达人 | 劳务报酬代扣 | 需发票 |

## 六、应急处理

### 6.1 发生劳动争议

1. 立即停止争议行为
2. 收集证据（协议、付款记录、沟通记录）
3. HR+法务介入
4. 优先协商解决
5. 协商不成走劳动仲裁

### 6.2 发生工伤

1. 立即送医
2. 保留医疗记录
3. 30日内申报工伤（全日制/非全日制）
4. 非全日制走工伤保险
5. 实习生走商业保险

## 七、检查清单

| 检查项 | 频率 |
|--------|------|
| 灵活用工协议是否齐全 | 每月 |
| 是否有以灵活用工名义实际全日制用工 | 每季度 |
| 工伤险是否足额缴纳 | 每月 |
| 商业意外险是否有效 | 每季度 |
| 发票/收据是否齐全 | 每月 |
| 是否有考勤打卡（不该有的） | 每季度 |

## 八、注意事项

1. **不能用灵活用工逃避社保**：明明是全日制用工，签"合作协议"没用，法院还是认劳动关系
2. **工时是关键**：非全日制超过工时就是全日制
3. **管理方式决定性质**：你怎么管人，法律就怎么认
4. **协议要签对**：不同用工类型用不同协议模板，不能混用
5. **证据要留好**：付款记录、沟通记录、协议都要留存，以备争议
