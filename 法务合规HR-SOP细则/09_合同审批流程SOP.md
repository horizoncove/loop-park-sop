# 09 合同审批流程SOP

> 适用范围：LoopPark 所有对内对外合同审批
> 版本：V1.0 | 生效日期：2026-09-19

---

## 一、合同分级

| 级别 | 标准 | 示例 | 审批流程 |
|------|------|------|----------|
| A级 | 标的额>50万，或涉及股权/投资/重大资产 | 母租赁合同、投资协议、股权转让 | 业务部门→法务→项目负责人→实控人 |
| B级 | 标的额10-50万，或常规业务合同 | 采购合同、商户租赁、服务合同 | 业务部门→法务→项目负责人 |
| C级 | 标的额<10万，或标准模板合同 | 兼职协议、小额采购、标准模板 | 业务部门→法务（抽查） |
| D级 | 内部文件、行政类 | 入职协议、保密协议 | 业务部门→HR |

---

## 二、审批流程图

```
业务部门发起
    │
    ▼
【第1步】部门负责人审核（1个工作日）
    │ 审核内容：业务必要性、预算匹配、商务条款
    ▼
【第2步】法务合规审查（2-5个工作日）
    │ 审查内容：法律风险、条款合法性、模板合规
    │ 输出：审查意见书（通过/修改/不通过）
    ▼
【第3步】财务审核（1个工作日，涉款合同）
    │ 审核内容：付款方式、发票、税务
    ▼
【第4步】项目负责人审批（1-2个工作日）
    │ A级还需实控人审批
    ▼
【第5步】定稿用印
    │ 填写用印申请单
    ▼
【第6步】归档
    │ 合同原件归档，电子件录入台账
```

## 三、各环节职责

### 3.1 业务部门（发起方）
- 提供合同背景说明
- 确认商务条款（价格、数量、交付时间）
- 提供对方资质文件
- 跟踪审批进度

### 3.2 部门负责人
- 确认业务必要性
- 确认预算已批复
- 确认商务条款合理

### 3.3 法务（合规审查）
- 审查合同主体合法性
- 审查条款完整性和合法性
- 识别法律风险并提出修改意见
- 出具审查意见书

### 3.4 财务
- 审核付款条件
- 确认发票要求
- 核对税务处理

### 3.5 项目负责人
- 最终决策审批
- 平衡风险与业务需求

## 四、时限要求

| 合同级别 | 部门审核 | 法务审查 | 财务审核 | 负责人审批 | 总计 |
|----------|----------|----------|----------|------------|------|
| A级 | 1天 | 5天 | 1天 | 2天 | 9天 |
| B级 | 1天 | 3天 | 1天 | 1天 | 6天 |
| C级 | 1天 | 2天 | - | - | 3天 |
| D级 | 1天 | 抽查 | - | - | 2天 |

**紧急合同：** 如需加急，在申请单标注"紧急"，法务优先处理，1个工作日内反馈。

---

## 五、审查意见分类

| 意见类型 | 含义 | 后续动作 |
|----------|------|----------|
| ✅ 通过 | 无法律风险，可直接签 | 进入审批流程 |
| ⚠️ 有条件通过 | 小修改后可签 | 业务部门按意见修改后重审 |
| ❌ 不通过 | 重大风险，不建议签 | 说明理由，业务部门重新谈判 |

## 六、合同台账管理

每签一份合同，法务需登记以下信息：

| 字段 | 说明 |
|------|------|
| 合同编号 | 按 LP-类别-年份-序号 编码 |
| 合同名称 | 全称 |
| 对方单位 | 签约方名称 |
| 标的额 | 合同总金额 |
| 签订日期 | 实际签订日 |
| 到期日期 | 合同终止日 |
| 归档位置 | 纸质/电子存档位置 |
| 续签提醒 | 到期前30天提醒 |

## 七、LoopPark 常用合同编号规则

```
LP - 类别 - 年份 - 序号
│    │      │      └─ 001起
│    │      └─ 2026
│    └─ LD=劳动、WG=务工、SX=实习、HR=合伙、DR=达人、
│       ZL=租赁、CG=采购、FW=服务、QT=其他
└─ LoopPark
```

示例：LP-ZL-2026-001 = 2026年第一份租赁合同
