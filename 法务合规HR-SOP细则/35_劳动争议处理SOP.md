# 35 劳动争议处理SOP

> 适用范围：LoopPark 全部劳动争议处理
> 法律依据：《劳动争议调解仲裁法》
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、常见劳动争议类型

| 类型 | 占比 | 高发场景 |
|------|------|----------|
| 拖欠工资/加班费 | 30% | 店员加班、活动加班 |
| 解除劳动合同 | 25% | 辞退试用期员工、违纪解除 |
| 未签劳动合同 | 20% | 新员工入职流程慢 |
| 社保补缴 | 15% | 灵活用工转全日制 |
| 经济补偿金 | 10% | 协商解除、合同到期 |

## 二、争议处理流程

### 2.1 内部处理（优先）

```
员工提出异议
    │
    ▼
部门负责人接待（24小时内）
    │
    ▼
HR介入调查（3日内）
    │
    ├─ 收集证据（合同/考勤/工资条/聊天记录）
    ├─ 核实事实
    └─ 评估法律风险
    ▼
拟定解决方案（3日内）
    │
    ├─ 合理诉求 → 协商解决
    └─ 不合理诉求 → 解释说明
    ▼
协商一致 → 签和解协议 → 结案
    │
    └─ 协商不成 → 员工可申请仲裁
```

### 2.2 外部处理

```
劳动仲裁
    │
    ├─ 员工申请（1年内）
    ├─ 公司收到通知 → 10日内提交答辩
    ├─ 仲裁开庭
    └─ 仲裁裁决
    ▼
不服裁决 → 15日内起诉法院
    │
    ├─ 一审
    └─ 二审（终审）
    ▼
执行
```

## 三、证据准备清单

| 争议类型 | 必备证据 |
|----------|----------|
| 工资争议 | 劳动合同、工资条、银行流水、考勤记录 |
| 解除争议 | 解除通知书、违纪证据、规章制度、员工签收 |
| 未签合同 | 入职登记表、实际用工证据、发薪记录 |
| 社保争议 | 劳动合同、工资基数、社保缴纳记录 |
| 加班费争议 | 考勤记录、加班审批表 |

## 五、不同争议的处理策略

### 5.1 工资/加班费争议

| 情况 | 处理策略 |
|------|----------|
| 确实拖欠 | 尽快补发，避免仲裁 |
| 加班费争议 | 看考勤记录，有记录就付，没记录就协商 |
| 员工要求过高 | 协商打折，签和解协议 |

### 5.2 解除劳动合同争议

| 情况 | 处理策略 |
|------|----------|
| 试用期解除 | 拿出不符合录用条件的证据 |
| 违纪解除 | 有制度依据+事实证据+程序合规 |
| 协商解除 | 给N倍经济补偿，签协议 |
| 违法解除风险高 | 建议协商，避免2N赔偿 |

### 5.3 未签劳动合同争议

| 情况 | 处理策略 |
|------|----------|
| 入职超1个月未签 | 双倍工资风险，尽快补签 |
| 员工拒签 | 保留拒签证据，书面通知 |

## 六、成本测算

| 争议类型 | 可能成本 | 和解成本 |
|----------|----------|----------|
| 拖欠工资 | 欠薪+25%赔偿 | 补发工资 |
| 违法解除 | 2N经济补偿 | N+1 |
| 未签合同 | 双倍工资差额 | 补签+少量补偿 |
| 社保补缴 | 补缴+滞纳金 | 补缴 |

## 七、预防措施

| 措施 | 说明 |
|------|------|
| 入职即签合同 | 入职当天签，不能拖 |
| 考勤记录完整 | 打卡数据留存2年 |
| 工资条员工签字 | 每月发薪确认 |
| 规章制度公示 | 员工手册签收 |
| 解除流程合规 | 证据充分、通知工会 |
| 离职签协议 | 离职时签"无争议"确认 |

---

## 八、注意事项

1. **仲裁时效1年**：员工知道权益被侵害起1年内要申请
2. **举证责任在公司**：工资/考勤/解除原因，公司要拿证据
3. **不要拖**：争议越早解决成本越低
4. **和解要签协议**：口头和解没用，必须书面+收款凭证
5. **找专业律师**：大额争议（>5万）建议请律师
6. **不要激化矛盾**：好好谈，避免员工走极端
