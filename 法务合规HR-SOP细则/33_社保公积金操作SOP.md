# 33 社保公积金操作SOP

> 适用范围：LoopPark 全日制员工
> 法律依据：《社会保险法》《住房公积金管理条例》
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、参保范围

| 用工类型 | 社保 | 公积金 | 备注 |
|----------|------|--------|------|
| 全日制员工 | 必缴 | 必缴 | 入职30日内办理 |
| 非全日制员工 | 工伤险 | 不缴 | 可只缴工伤 |
| 实习生 | 不缴 | 不缴 | 买商业意外险 |
| 校内合伙人 | 不缴 | 不缴 | 合作关系非劳动关系 |
| KOL达人 | 不缴 | 不缴 | 合作关系 |

## 三、新员工参保流程

```
员工入职
    │
    ▼
入职30日内办理
    │
    ├─ 收集材料：身份证复印件+一寸照片+社保转移单
    │
    ▼
社保系统增员
    │
    ├─ 登录西安市社保网上服务平台
    ├─ 录入员工信息
    └─ 提交增员申请
    ▼
公积金系统增员
    │
    ├─ 登录西安住房公积金网厅
    ├─ 录入员工信息
    └─ 提交开户/转移
    ▼
次月扣款
    │
    ▼
反馈员工（缴纳基数+比例）
```

---

## 四、离职减员流程

```
员工离职
    │
    ▼
离职当月15日前提交减员
    │
    ├─ 社保系统减员
    └─ 公积金系统减员
    ▼
办理社保转移（如需）
    │
    ├─ 开具《参保缴费凭证》
    └─ 员工自行办理转移
    ▼
公积金提取/转移（如需）
    │
    ├─ 离职后可申请提取
    └─ 或转移到新单位
```

## 五、年度操作

### 5.1 每年7月：社保基数调整

1. 按员工上年度月平均工资重新申报基数
2. 新入职按首月工资申报
3. 基数在上下限之间

### 5.2 每年7月：公积金基数调整

1. 按员工上年度月平均工资调整
2. 每年只能调整一次

## 六、特殊情况处理

| 情况 | 处理方式 |
|------|----------|
| 员工自愿不缴社保 | 无效，必须缴（法律强制） |
| 试用期不缴 | 违法，入职即缴 |
| 员工要求发现金补贴 | 不行，必须走社保账户 |
| 异地员工 | 在工作地缴纳 |
| 兼职/小时工 | 只缴工伤险 |

## 八、注意事项

1. **必须入职即缴**：试用期不缴社保是违法的
2. **自愿放弃无效**：员工签的"自愿不缴社保"协议无效，仍需补缴
3. **不能发现金替代**：用现金补贴替代社保是违法的
4. **基数要真实**：按实际工资申报，不能按最低基数交
5. **及时减员**：离职后及时减员，避免多缴
