# 32 员工奖惩管理制度

> 适用范围：LoopPark 全体全日制员工
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、总则

1. 为规范员工行为，激励先进、纠正违纪，制定本制度
2. 奖惩以事实为依据，公开公平公正
3. 所有奖惩均需书面记录，存入员工档案

---

## 二、奖励

### 2.1 奖励类型

| 类型 | 适用情形 | 奖励方式 |
|------|----------|----------|
| 通报表扬 | 工作表现突出，获客户好评 | 全公司通报 |
| 奖金 | 重大贡献/超额完成目标 | 500-5000元 |
| 晋升 | 能力出众，绩效连续S/A | 岗位+薪资提升 |
| 调薪 | 年度绩效优秀 | 薪资调整5-20% |

### 2.2 奖励流程

```
部门负责人提名
    │
    ▼
HR审核
    │
    ▼
项目负责人审批
    │
    ▼
公示3天
    │
    ▼
执行奖励+归档
```

---

## 三、违纪处分

### 3.1 违纪分级

| 级别 | 定义 | 示例 |
|------|------|------|
| 轻微违纪 | 不影响工作的小过失 | 迟到/忘打卡/着装不规范 |
| 一般违纪 | 影响工作质量或团队 | 工作失误/散布谣言/迟到多次 |
| 严重违纪 | 严重违反制度/损害公司利益 | 泄露秘密/受贿/旷工/打架 |
| 重大违纪 | 触犯法律/重大损失 | 贪污/盗窃/严重渎职 |

### 3.2 处分措施

| 违纪级别 | 处分 | 经济处罚 |
|----------|------|----------|
| 轻微 | 口头警告 | 扣50-200元 |
| 一般 | 书面警告+绩效扣减 | 扣200-500元 |
| 严重 | 记过+降薪/调岗 | 扣500-2000元 |
| 重大 | 解除劳动合同 | 追究赔偿/法律责任 |

---

## 四、常见违纪行为及处分

### 4.1 考勤类

| 行为 | 处分 |
|------|------|
| 迟到≤10分钟 | 扣50元 |
| 迟到10-30分钟 | 扣100元 |
| 迟到30分钟以上 | 旷工半天 |
| 月迟到≥5次 | 书面警告 |
| 旷工1天 | 扣3倍日薪+书面警告 |
| 连续旷工3天 | 解除劳动合同 |

### 4.2 工作纪律类

| 行为 | 处分 |
|------|------|
| 工作时间做私事 | 口头警告 |
| 未按规定流程操作 | 书面警告 |
| 工作失误造成损失 | 按损失大小处分 |
| 代打卡 | 双方各扣500元+书面警告 |
| 不服从工作安排 | 书面警告→调岗→解除 |

### 4.3 合规红线类（P0）

| 行为 | 处分 |
|------|------|
| 销售过期/不合格食品 | 立即解除合同 |
| 向未成年人售酒 | 立即解除合同 |
| 收受供应商回扣 | 立即解除合同+追偿 |
| 泄露公司商业秘密 | 立即解除合同+追责 |
| 私自挪用货款 | 立即解除合同+报警 |
| 虚假报销 | 立即解除合同+退款 |

### 4.4 行为规范类

| 行为 | 处分 |
|------|------|
| 与客户争吵 | 书面警告 |
| 在工作场所饮酒 | 书面警告 |
| 传播负能量/谣言 | 书面警告→解除 |
| 打架斗殴 | 解除合同 |

## 五、处分流程

```
发现违纪行为
    │
    ▼
部门负责人调查核实（2天内）
    │
    ▼
HR审核证据
    │
    ▼
拟定处分决定
    │
    ├─ 轻微/一般 → 部门负责人审批
    └─ 严重/重大 → 项目负责人审批
    ▼
书面通知员工（签字确认）
    │
    ▼
员工可3日内申诉
    │
    ▼
执行处分+归档
```

---

## 六、申诉机制

1. 员工对处分不服，可在收到通知3日内向HR书面申诉
2. HR+项目负责人5日内复核
3. 复核结果为最终决定

---

## 七、注意事项

1. **处罚要有依据**：所有处分必须对照本制度条款，不能凭感觉罚
2. **事实要清楚**：处分前必须调查核实，有书面证据
3. **程序要合规**：严重/重大处分必须通知工会（如有）
4. **罚款不能乱扣**：每月扣款不得超过工资20%，且不低于最低工资
5. **解除要谨慎**：解除合同必须有充分证据，避免劳动争议
