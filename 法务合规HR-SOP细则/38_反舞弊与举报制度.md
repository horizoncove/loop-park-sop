# 38 反舞弊与举报制度

> 适用范围：LoopPark 全体员工/供应商/合伙人
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、反舞弊总则

1. 为防范舞弊行为，保护公司财产和声誉，制定本制度
2. 舞弊行为包括：贪污、受贿、侵占、虚假报销、利益输送等
3. 公司鼓励员工/供应商举报舞弊行为

---

## 二、常见舞弊行为

### 2.1 采购/供应链类

| 行为 | 表现 |
|------|------|
| 收受回扣 | 采购时拿供应商好处费 |
| 虚报采购价 | 高价采购，吃差价 |
| 关联交易 | 采购自己亲戚的公司 |
| 串通供应商 | 和供应商串通虚报数量 |

### 2.2 财务/行政类

| 行为 | 表现 |
|------|------|
| 虚假报销 | 虚报发票/虚增金额 |
| 挪用公款 | 把公司钱挪作私用 |
| 私设小金库 | 账外资金 |
| 虚报工资 | 吃空饷 |

### 2.3 销售/运营类

| 行为 | 表现 |
|------|------|
| 私吞货款 | 收了钱不上交 |
| 低价卖货 | 低价卖给熟人 |
| 虚报活动费用 | 活动费用虚报 |
| 侵占库存 | 私自拿商品 |

| 渠道 | 方式 | 受理人 |
|------|------|--------|

## 四、举报受理流程

```
收到举报
    │
    ▼
登记举报信息（24小时内）
    │
    ├─ 举报时间
    ├─ 被举报人
    ├─ 举报事项
    └─ 证据线索
    ▼
初步评估（3日内）
    │
    ├─ 线索清晰 → 正式调查
    └─ 线索不足 → 补充材料
    ▼
正式调查
    │
    ├─ 收集证据
    ├─ 约谈相关人员
    └─ 核实事实
    ▼
调查结论
    │
    ├─ 属实 → 处分/追责
    ├─ 部分属实 → 部分处理
    └─ 不属实 → 澄清
    ▼
反馈举报人
```

## 五、举报人保护

1. **严格保密**：举报信息严格保密，不得泄露举报人身份
2. **禁止报复**：任何人不得打击报复举报人
3. **匿名举报**：接受匿名举报
4. **奖励**：举报属实的，给予举报人奖励

### 奖励标准

| 追回金额 | 奖励比例 |
|----------|----------|
| 1万以下 | 10% |
| 1-10万 | 5-10% |
| 10万以上 | 3-5% |

---

## 六、舞弊处分

| 情节 | 处分 |
|------|------|
| 金额<5000元 | 警告+退赔+罚款 |
| 5000-5万 | 解除合同+退赔+罚款 |
| 5万以上 | 解除合同+退赔+报警 |
| 供应商舞弊 | 终止合作+列入黑名单+追偿 |

---

## 七、预防措施

| 措施 | 说明 |
|------|------|
| 采购审批分离 | 采购人和审批人分开 |
| 定期盘点 | 库存定期盘点 |
| 费用审批 | 费用多级审批 |
| 轮岗制度 | 关键岗位定期轮岗 |
| 供应商轮换 | 定期更换供应商 |
| 举报渠道畅通 | 多种举报方式 |

---

## 八、注意事项

1. **举报要属实**：诬告陷害要承担责任
2. **调查要客观**：不能先入为主，要讲证据
3. **保密最重要**：泄露举报人信息是严重违纪
4. **及时处理**：举报不能拖，越拖越难查
5. **供应商也要管**：舞弊不只在内部，供应商也要防
