# 36 供应商合规准入清单

> 适用范围：LoopPark 宝藏星球采购、自营业态采购、活动供应商
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、供应商类型

| 类型 | 示例 | 准入要求 |
|------|------|----------|
| 食品供应商 | 零食/饮品/预包装食品 | 必须有食品经营许可证 |
| 礼品供应商 | 宝藏星球1200SKU | 营业执照+质检报告 |
| 设备供应商 | 货架/冷柜/收银设备 | 营业执照+售后承诺 |
| 活动供应商 | 搭建/演出/物料 | 营业执照+安全资质 |
| 服务供应商 | 清洁/安保/维修 | 营业执照+人员资质 |

---

## 二、通用准入清单

### 2.1 资质文件（必查）

| 检查项 | 要求 | 是否合格 |
|--------|------|----------|
| 营业执照 | 在有效期内，经营范围匹配 | □是 □否 |
| 法定代表人身份证 | 与营业执照一致 | □是 □否 |
| 银行开户许可证 | 与收款账户一致 | □是 □否 |
| 一般纳税人资格 | 能开增值税专用发票 | □是 □否 |
| 近1年财务报表 | 经营正常 | □是 □否 |

### 2.2 信用调查（必查）

| 检查项 | 查询渠道 | 要求 |
|--------|----------|------|
| 经营异常名录 | 国家企业信用信息公示系统 | 不在异常名录 |
| 严重违法失信名单 | 同上 | 不在黑名单 |
| 涉诉记录 | 中国裁判文书网 | 无重大诉讼 |
| 被执行人记录 | 中国执行信息公开网 | 非被执行人 |

### 2.3 合同条款（必签）

| 条款 | 要求 |
|------|------|
| 质量标准 | 明确产品质量标准 |
| 验收标准 | 明确验收方式 |
| 退换货 | 临期/破损退换货规则 |
| 发票 | 开票时间+发票类型 |
| 账期 | 付款时间 |
| 违约责任 | 质量问题/逾期交货赔偿 |
| 知识产权 | 产品不侵权承诺 |
| 保密条款 | 双方保密义务 |

## 三、食品供应商专项

### 3.1 必查资质

| 检查项 | 要求 |
|--------|------|
| 食品经营许可证 | 在有效期内 |
| 食品生产许可证 | 生产商有SC证 |
| 检验检疫报告 | 每批次有质检报告 |
| 供货商资质 | 上游经销商有授权 |

### 3.2 进货查验清单

| 检查项 | 要求 |
|--------|------|
| 生产日期 | 进货时剩余保质期≥2/3 |
| 保质期标识 | 清晰可辨 |
| 包装完好 | 无破损/胀袋/漏气 |
| 中文标签 | 有完整中文标签 |
| 进口食品 | 有中文标签+报关单 |

## 五、准入审批流程

```
供应商申请
    │
    ▼
收集资质文件
    │
    ├─ 营业执照
    ├─ 行业资质
    └─ 信用调查
    ▼
采购部门初审
    │
    ▼
法务合规审核
    │
    ├─ 合同条款
    ├─ 资质真实性
    └─ 信用风险
    ▼
财务审核
    │
    ├─ 账期
    └─ 付款方式
    ▼
项目负责人审批
    │
    ▼
纳入合格供应商名录
    │
    ▼
开始合作
```

## 六、供应商分级

| 等级 | 标准 | 合作策略 |
|------|------|----------|
| A级（战略） | 合作1年以上，无问题，价格优 | 长期合作，优先付款 |
| B级（合格） | 资质齐全，正常合作 | 正常合作 |
| C级（观察） | 有小问题，需整改 | 小单试合作 |
| D级（淘汰） | 有严重问题/失信 | 终止合作，列入黑名单 |

---

## 七、年度复审

| 时间 | 事项 |
|------|------|
| 每年1月 | 复审上年度供应商 |
| 每年2月 | 更新合格供应商名录 |
| 每年3月 | 新供应商准入评估 |

---

## 八、注意事项

1. **先审后签**：必须资质审核通过再签合同，不能先合作后补手续
2. **资质要验原件**：不能只看复印件，要核对原件或官网验证
3. **食品供应商最严**：食品出问题是大事，资质必须齐全
4. **黑名单制度**：出过问题的供应商永久不合作
5. **定期复审**：供应商资质会过期，每年要重新审
