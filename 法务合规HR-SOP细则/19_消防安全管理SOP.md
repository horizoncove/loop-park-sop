# 19 消防安全管理SOP

> 适用场景：LoopPark 全园区（3万㎡商业街区）
> 法律依据：《消防法》《人员密集场所消防安全管理》
> 版本：V1.0 | 生效日期：2026-09-19

---

## 一、责任体系

法定代表人（第一责任人）→ 消防安全管理人（火将）→ 各区域安全员 + 各业态负责人

---

## 二、日常巡查

### 每日巡查
- [ ] 疏散通道畅通
- [ ] 安全出口畅通
- [ ] 灭火器在位有效
- [ ] 消火栓无遮挡
- [ ] 应急照明正常
- [ ] 疏散标识清晰
- [ ] 用火用电规范
- [ ] 消控室有人值班

### 每周检查
- [ ] 灭火器压力
- [ ] 消火栓水压
- [ ] 烟感/温感测试
- [ ] 防火门关闭正常
- [ ] 无电动自行车进店充电

### 每月全面检查
- [ ] 消防水泵测试
- [ ] 喷淋系统测试
- [ ] 防火卷帘测试
- [ ] 排烟系统测试
- [ ] 消防器材台账核对

---

## 三、设施配置标准

| 区域 | 必配 |
|------|------|
| 营业区 | 灭火器、应急照明、疏散指示 |
| 仓库 | 灭火器、烟感、喷淋 |
| 餐饮厨房 | 灭火器、灭火毯、燃气报警 |
| 配电室 | 气体灭火器、烟感 |
| 楼梯间 | 应急照明、防火门 |

---

## 四、用火用电管理

- 营业区严禁明火，动火需办动火证
- 严禁私拉乱接、超负荷用电
- 配电箱周围1米内不堆物
- 每日闭店切断非必要电源
- 电动自行车严禁进店充电

---

## 五、疏散通道管理（P0红线）

- 任何时候通道和出口必须畅通
- 通道宽度≥1.4米
- 安全出口严禁上锁
- 严禁通道堆货/摆摊
- 疏散门向疏散方向开启

---

## 六、培训与演练

- 新员工入职：报警程序+灭火器使用+疏散路线
- 全员培训：每半年1次
- 消防演练：每半年至少1次（报警→疏散→灭火→救护）

---

## 七、活动期间消防

- 大型活动前额外配灭火器
- 确认摊位不占疏散通道
- 临时用电线路检查
- 专人消防值班
- 每个市集摊位配1个灭火器

---

## 八、火灾应急流程

发现火情 → 呼喊报警 → 初期火灾用灭火器 → 火势大按手报+打119 → 通知消控室 → 组织疏散 → 引导消防车 → 清点人数

---

## 九、消防档案

消防验收意见书 / 设施分布图 / 检测报告 / 巡查记录 / 培训演练记录 / 隐患整改记录 / 灭火器台账

---

## 十、注意事项

1. 火将一票否决：消防问题可直接叫停营业
2. 通道不能堵：市集再多摊位，疏散通道必须留够
3. 每人都会用灭火器
4. 每日闭店三步：关灯、断电、锁门
5. 电动自行车绝对不能进店充电
