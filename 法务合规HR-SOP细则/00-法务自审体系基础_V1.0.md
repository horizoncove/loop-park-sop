## 一、目的与定位

建立 LOOP PARK 法务合规的**自我审查机制**，把合规管理从"出事后补救"转为"定期自检、主动纠偏"。

本文件是自审体系的**基础框架**（制度 + 流程 + 记录模板），具体检查项以《法务合同评估平台》内置的风险清单（11 类风险域 × 9 类合同 × 60+ 检查项）为执行工具。

**适用对象：** 法务合规负责人牵头，各业态/部门负责人配合，全员按检查项自查。

---

## 二、自审四项原则

| 原则 | 要求 |
|------|------|
| **1. 定期性** | 按固定周期执行，不等出事才查（月度 + 季度 + 关键节点） |
| **2. 独立性** | 自审结果直接报法务负责人/管理层，业务部门不得自行"消化"问题 |
| **3. 留痕性** | 每次自审必须填写记录表并归档，检查-整改-复核全链条留痕 |
| **4. 闭环性** | 发现问题 → 整改 → 复核 → 复盘沉淀，不允许"查完就完" |

## 三、自审频次与触发节点

| 类型 | 频次 | 范围 | 负责人 |
|------|------|------|--------|
| **月度自查** | 每月 1-5 日 | 高风险域（用工/食安/未成年保护/消费纠纷） | 法务 + 各业态店长 |
| **季度全面自审** | 每季度首月 | 11 类风险域全覆盖 | 法务牵头，全员配合 |
| **开业前全量自审** | 试营业（2027-05-30）前 60 天 | 证照/消防/食安/用工/合同全量 | 法务 + 管理层 |
| **事件触发自审** | 发生投诉、处罚、纠纷、舆情后 7 日内 | 相关风险域专项复查 | 法务 |
| **合同签约前评估** | 每份合同签署前 | 按合同类型走评估器 | 业务发起人 + 法务 |

## 五、自审流程（六步闭环）

```
① 制定计划 → ② 逐项自查 → ③ 填写记录 → ④ 整改 → ⑤ 复核 → ⑥ 复盘归档
   (范围/时间/    (对照评估器    (按记录表    (责任人/     (验证整改    (问题沉淀进
    责任人)      与检查清单)    打分分级)    期限/方案)   是否有效)    风险知识库)
```

1. **制定计划**：明确本次自审范围、时间、责任人（参照第三节频次表）。
2. **逐项自查**：打开《法务合同评估平台》→ 对应合同类型/风险域 → 逐项核查，如实选择"符合/不符合/不确定"。
3. **填写记录**：将结果记入《自审记录表》（模板见第六节），得出风险分与等级。
4. **整改**：红色项立即停止相关动作并法务介入；橙色项 15 日内完成整改；整改方案写明责任人、期限、措施。
5. **复核**：到期后法务复核整改有效性，未闭环的升级上报管理层。
6. **复盘归档**：每季度把自审发现的问题、教训、改进项沉淀进"10-风险知识库"，更新检查清单。

## 七、分级与处置规则

| 等级 | 判定 | 处置要求 |
|------|------|---------|
| 🔴 红 | 风险分 ≥5 或命中一票否决项（无证经营/售酒给未成年/重大安全隐患） | 立即停止相关业务动作，法务介入，24 小时内上报管理层，7 日内整改并复核 |
| 🟠 橙 | 风险分 2-4.9 | 15 日内完成整改，整改后复核销项；连续两月同项橙色升级为红色处置 |
| 🟢 绿 | 风险分 <2 | 正常运行，按周期复查 |

**一票否决项（无论分值直接红色）：**
- 无证经营（食品/酒类/娱乐等许可缺失）
- 向未成年人售酒或允许进入限制场所
- 消防设施缺失或疏散通道堵塞
- 被认定事实劳动关系而未缴社保
- 严重违反广告法（极限词/虚假宣传情节严重）

## 九、与现有体系的联动

1. **与评估平台**：自审即平台评估流程的批量执行；平台清单由自审复盘持续增补。
2. **与 SOP 库**：自审发现的制度缺失 → 新增/修订对应 SOP（40 份细则体系）。
3. **与合同台账**：签约前评估结果与合同台账联动，未评估合同不得用印（对接 08 用印申请）。
4. **与档案库**：全部自审记录入档，形成"风险发生-应对-沉淀"的完整证据链。
5. **与月报**：每月自审结果摘入法务合规月报，向管理层汇报。
