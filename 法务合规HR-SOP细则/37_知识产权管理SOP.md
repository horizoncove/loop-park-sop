## 二、商标管理

### 2.1 商标注册流程

```
确定商标名称/图形
    │
    ▼
商标查询（避免近似）
    │
    ├─ 中国商标网查询
    └─ 类别：第35类（广告销售）、第41类（娱乐活动）、第43类（餐饮住宿）
    ▼
准备材料
    │
    ├─ 营业执照
    ├─ 商标图样
    └─ 商品/服务项目
    ▼
提交申请（找代理机构）
    │
    ▼
形式审查（1个月）
    │
    ▼
实质审查（6-9个月）
    │
    ▼
初审公告（3个月）
    │
    ▼
注册发证（总周期约12个月）
```

### 2.2 必须注册的类别

| 类别 | 覆盖业务 | 优先级 |
|------|----------|--------|
| 第35类 | 广告/零售/商业管理 | P0 |
| 第41类 | 娱乐/活动/组织比赛 | P0 |
| 第43类 | 餐饮/咖啡/小酒馆 | P1 |
| 第25类 | 周边产品（T恤/帽子） | P2 |

## 三、著作权管理

### 3.1 哪些作品有著作权

| 作品 | 作者归属 | 保护期 |
|------|----------|--------|
| IP形象设计图 | 公司（员工/外包） | 50年 |
| 活动海报/宣传物料 | 公司 | 50年 |
| 文案/脚本 | 公司 | 50年 |
| 摄影/视频作品 | 公司 | 50年 |
| 软件/小程序 | 公司 | 50年 |

### 3.2 外包设计合同必须写

1. **著作权归属**：归甲方（LoopPark）所有
2. **不得擅自使用**：乙方不得将作品用于其他用途
3. **不得侵权**：乙方保证作品不侵犯第三方权利
4. **交付源文件**：交付PSD/AI等源文件

## 四、IP形象管理

### 4.1 IP形象使用规范

| 规范 | 要求 |
|------|------|
| 比例 | 不得拉伸变形 |
| 颜色 | 按标准色值使用，不得随意改色 |
| 最小尺寸 | 印刷≥2cm，屏幕≥50px |
| 背景 | 不得放在杂乱背景上 |
| 修改 | 不得随意添加/删除元素 |

### 4.2 IP形象授权

1. 对外授权必须签书面授权协议
2. 明确授权范围（产品/宣传/期限）
3. 明确授权费用（一次性/分成）
4. 明确质量要求（不得丑化）
5. 禁止转授权

## 五、侵权风险防控

### 5.1 常见侵权类型

| 类型 | 场景 | 防控 |
|------|------|------|
| 商标侵权 | 别人用类似名字 | 注册商标+监控 |
| 字体侵权 | 海报用了未授权字体 | 用免费字体/买商用授权 |
| 图片侵权 | 宣传图用了网图 | 用正版图库/自制 |
| 音乐侵权 | 活动放未授权音乐 | 买版权/用免费BGM |
| 形象侵权 | 用了别人卡通形象 | 自己设计/买授权 |

### 5.2 免费商用资源

| 类型 | 推荐资源 |
|------|----------|
| 字体 | 思源黑体/思源宋体/站酷免费字体 |
| 图片 | Unsplash/Pexels/Pixabay |
| 音乐 | YouTube音频库/爱给网免费区 |
| 图标 | Lucide/MORPHICONS |

## 七、侵权应对

```
发现侵权
    │
    ▼
固定证据（截图/录屏/公证）
    │
    ▼
评估侵权程度
    │
    ├─ 轻微 → 发律师函警告
    ├─ 中等 → 协商赔偿
    └─ 严重 → 起诉
    ▼
维权
```

## 八、注意事项

1. **商标要早注册**：先注册再使用，别被别人抢注
2. **字体最容易出事**：很多公司因为一张海报字体被索赔几万，一定要用免费字体或买授权
3. **外包合同写清楚**：不写著作权归属，默认归创作者
4. **证据要固定**：发现侵权先截图/录屏，最好公证
5. **IP形象要规范**：用乱了就贬值了，必须有使用规范
