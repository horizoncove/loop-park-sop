# 食品经营许可证办理指南

> 适用主体：陕西中芯华影科技有限公司及街区内餐饮商户
> 办理部门：西咸新区市场监督管理局沣西新城分局
> 版本：V1.0

---

## 一、哪些情况需要办

| 业态 | 是否需要食品经营许可证 |
|------|----------------------|
| 卖预包装食品（瓶装水、零食、饮料） | ✅ 需要（仅销售预包装食品备案） |
| 现场制售（奶茶、咖啡、小吃） | ✅ 需要 |
| 餐饮服务（餐厅、食堂） | ✅ 需要 |
| 卖散装食品 | ✅ 需要 |
| 卖保健食品 | ✅ 需要（含特殊食品项） |

## 三、办理流程

```
准备材料 → 线上/现场提交 → 形式审查（5个工作日）
    → 现场核查（10个工作日内）→ 整改（如需）
    → 领取许可证（5个工作日）
```

**总时长：约20-30个工作日**

---

## 四、现场核查重点（提前准备好）

### 4.1 场所布局
- 食品处理区与生活区分离
- 生熟分开、荤素分开
- 有独立的消毒区、保洁区
- 地面墙面易清洗、有地漏

### 4.2 设备要求
- 冷藏冷冻设备正常运行
- 餐具消毒设施（消毒柜/紫外线灯）
- 防蝇防鼠设施（纱窗、挡鼠板、灭蝇灯）
- 垃圾桶带盖

### 4.3 人员要求
- 所有接触食品员工持有健康证
- 有食品安全管理员

## 五、仅销售预包装食品备案（简化版）

如果只是卖预包装食品（不开火、不现场制售），现在**不需要办食品经营许可证**，只需要做备案：

- 办理部门：市场监管局
- 材料：备案表+营业执照+经营场所平面图
- 时长：当场或3个工作日
- 费用：0

> 宝藏星球如果只卖预包装零食饮料，走这个备案就行，比许可证简单很多。

## 六、常见踩坑点

1. **健康证过期**：员工健康证要在有效期内，提前30天复查
2. **现场核查不过**：最常见的是生熟不分、消毒设施不到位、防蝇防鼠缺失
3. **地址不符**：实际经营地址要和营业执照一致
4. **从业人员无健康证**：被查到直接罚款
5. **许可证悬挂**：拿到证后要挂在显眼位置，检查时要看
