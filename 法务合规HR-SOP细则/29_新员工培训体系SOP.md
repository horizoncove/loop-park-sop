# 29 新员工培训体系SOP

> 适用范围：LoopPark 全体新入职员工（全日制+兼职+实习生）
> 版本：V1.0 | 生效日期：2026-09-20

---

## 一、培训目标

1. **快速融入**：让新员工1周内了解公司、团队、业务
2. **合规上岗**：确保新员工掌握必要的合规红线和安全知识
3. **技能达标**：岗位技能培训合格后方可独立上岗
4. **文化认同**：理解LoopPark青年街区的理念和氛围

---

## 二、培训分层

| 层级 | 培训对象 | 时长 | 负责部门 |
|------|----------|------|----------|
| L1-入职通识 | 所有新员工 | 1天 | HR+法务 |
| L2-部门培训 | 各部门新员工 | 3天 | 部门负责人 |
| L3-岗位实操 | 具体岗位 | 7天 | 带教师傅 |
| L4-转正考核 | 试用期满前 | 1次 | HR+部门 |

---

## 三、L1 入职通识培训（1天）

### 上午：公司介绍（2小时）
- 公司发展历程与愿景
- 千门八将组织架构介绍
- LOOP PARK项目概况（位置/定位/业态）
- 企业文化与价值观

### 下午：合规与安全（3小时）
- **合规红线（必讲）**
  - 食品安全：无证不得接触食品/过期食品必销毁
  - 消防安全：灭火器使用/疏散路线/不堵塞通道
  - 广告合规：不得使用极限词/不得虚假宣传
  - 数据安全：不得泄露客户信息
  - 反舞弊：不得收受回扣/不得私收货款
- 员工手册核心条款
- 考勤/薪酬/绩效制度介绍

### 当日考核
- 合规知识小测验（10题，80分合格）
- 不合格者补考，补考不合格延长试用期

---

## 四、L2 部门培训（3天）

| 天数 | 内容 |
|------|------|
| Day1 | 部门职能介绍/团队认识/工作流程 |
| Day2 | 业务流程学习/系统操作培训 |
| Day3 | 跟随老员工观察/模拟操作 |

---

## 五、L3 岗位实操（7天）

### 带教制度
- 每位新员工配1名带教师傅
- 带教师傅负责实操指导
- 每日填写《带教日志》
- 第7天进行岗位技能考核

### 带教日志模板

| 日期 | 学习内容 | 掌握情况 | 师傅签字 |
|------|----------|----------|----------|
| Day1 | | □熟练 □基本掌握 □未掌握 | |
| Day2 | | □熟练 □基本掌握 □未掌握 | |
| ... | | | |

---

## 六、各岗位培训重点

### 6.1 宝藏星球店员
- 商品陈列与补货
- 收银系统操作
- 临期食品识别与处理
- 顾客接待话术
- 盘点流程

### 6.2 自习室店员
- 会员系统操作
- 环境维护标准
- 设备故障处理
- 夜班注意事项

### 6.3 八将核心岗
- 岗位职责详解
- 跨部门协作流程
- 议事规则与汇报线
- 分管业务的SOP学习

### 6.4 兼职/实习生
- 只培训上岗必需内容
- 重点：合规红线+岗位基础操作
- 不做深度文化培训

---

## 七、转正考核

试用期满前7天进行转正考核：
- L1通识考核（合规知识）
- L3实操考核（岗位技能）
- 360度评价（同事反馈）

考核结果：合格转正 / 延长试用期1个月 / 不符合录用条件

---

## 八、培训记录归档

每位新员工建立培训档案：
- 入职培训签到表
- 合规测验成绩单
- 带教日志
- 转正考核表
- 全部归入员工人事档案

---

## 九、注意事项

1. **合规培训是红线**：必须通过才能上岗，不能走过场
2. **带教师傅有奖**：徒弟转正后，师傅奖励500元
3. **兼职也要培训**：哪怕只做1天，也要讲合规红线
4. **培训留痕**：所有培训签到、测验成绩都要存档
5. **定期复训**：每半年组织1次全员合规复训
