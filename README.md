# LOOP PARK SOP 知识库

沣西新城青年商业街区 · 法务合规HR SOP 细则仓库

---

## 仓库结构

```
LOOP-PARK-SOP/
├── 法务合规HR-SOP细则/     ← 40份法务合规HR制度文档
├── 工作SOP/                ← 日常运营SOP
├── 舆情监测/               ← 舆情监测体系
├── 内容创作/               ← 内容创作规范
├── 爬虫脚本/               ← 数据采集脚本
├── docs/                   ← 设计文档与方案
├── scripts/                ← 同步与部署脚本
├── pages/                  ← 静态页面（公寓介绍等）
├── apps/                   ← 前端应用（事件看板等）
├── deploy/                 ← 部署配置
└── .agents/                ← Agent 配置
```
