# 5km全域舆情监测系统方案（升级版）

> **版本：** V2.1
> **生效日期：** 2026-09-25
> **监测范围：** LOOP PARK周边5公里全域，全平台
> **对齐：** KB《舆情防控与宣传策略SOP》定稿（2026-09-20）· 数字纪律：不发明覆盖度百分比

---

## 一、监测平台矩阵

| 平台 | 监测内容 | 用什么工具 | 覆盖状态 |
|------|---------|-----------|--------|
| **抖音** | 周边探店视频、博主、评论区 | 通用搜索 + 博主列表监测 | 已打通（浏览器登录态） |
| **小红书** | 周边种草笔记、博主、评论 | 通用搜索 + 关键词监测 | 已打通（浏览器登录态） |
| **大众点评** | 周边商户评价、评分、差评 | 通用搜索 | 仅公开搜索 |
| **美团** | 周边商户销量、评价 | 通用搜索 | 仅公开搜索 |
| **高德地图** | 周边新开业商户、位置、评分 | 通用搜索 | 仅公开搜索 |
| **微博** | 本地热点、学生吐槽 | 通用搜索 | 仅公开搜索 |
| **B站** | 周边探店UP主 | 通用搜索 | 仅公开搜索 |
| **百度地图** | 周边商户、评论 | 通用搜索 | 仅公开搜索 |

> 覆盖状态三档定义：**已打通** = 登录态可采集；**仅公开搜索** = 只能抓公开内容；**未覆盖** = 完全无采集渠道（当前各平台后台完整数据与实时监控均属此类，详见 §五）。

## 二、分平台监测维度

### 2.1 抖音监测什么？

| 维度 | 具体内容 |
|------|---------|
| **视频内容** | 周边5km内的探店、夜市、学校相关视频 |
| **博主动态** | 我们S/A/B级博主最近发了什么 |
| **评论区** | 学生在评论里吐槽什么、问什么 |
| **爆款标签** | 哪些话题标签在周边学生里火 |

### 2.2 小红书监测什么？

| 维度 | 具体内容 |
|------|---------|
| **笔记内容** | 周边租房、美食、探店、攻略笔记 |
| **博主动态** | 校园KOC最近发了什么 |
| **评论区** | 学生在问什么问题 |
| **搜索关键词** | 学生在搜什么（比如"陕服周边租房"） |

### 2.3 大众点评/美团监测什么？

| 维度 | 具体内容 |
|------|---------|
| **周边商户** | 新开了什么店 |
| **评分变化** | 周边商户评分涨了还是跌了 |
| **差评内容** | 学生在吐槽什么（菜不好吃？服务差？） |
| **销量榜单** | 周边什么店卖得好 |

### 2.4 高德/百度地图监测什么？

| 维度 | 具体内容 |
|------|---------|
| **新开商户** | 周边新开业的店 |
| **商户评论** | 地图上的评论 |
| **打卡热度** | 哪些地方学生爱去打卡 |

## 三、每日监测执行流程

### 早上9点：自动跑通用搜索
```
1. 品牌关键词扫描（LOOP PARK相关）
2. 竞品关键词扫描（吾悦/星空夜市）
3. 高校关键词扫描（4所学校）
4. 周边商户扫描（新开业、差评）
5. 爆款内容扫描（周边热门视频/笔记）
```

### 每周一：深度博主监测
```
1. S级博主最近发了什么
2. A级校园KOC最近发了什么
3. 有没有新冒出来的周边博主
4. 博主粉丝量变化
```

### 每月初：竞品深度调研
```
1. 竞品最近做了什么活动
2. 竞品人流变化
3. 竞品新入驻商户
4. 我们的差异化机会
```

## 五、当前限制说明

**能做到的：**
- ✅ 通用搜索抓到的公开内容
- ✅ 博主公开的视频/笔记内容
- ✅ 新闻报道、政府公告
- ✅ 商户公开的评分和评价摘要

**做不到的：**
- ❌ 抖音/小红书后台完整评论区（需要登录+反爬）
- ❌ 博主粉丝画像详细数据（需要付费数据平台）
- ❌ 实时监控（只能每天跑一次）
- ❌ 大众点评完整差评列表（需要登录）

> 这些平台反爬很严，直接爬会被封。
> 以后如果需要更深度的，可以买数据平台（飞瓜、新红）的会员，或者用浏览器手动看。
