## 核心原则

1. **没事不打扰**：日常小负面我直接处理，事后归档
2. **有事必上报**：黄色以上级别立刻通知，附建议方案
3. **处理有记录**：每一次舆情都记录在案，形成案例库
4. **速度优先**：第一时间响应，态度比事实重要
