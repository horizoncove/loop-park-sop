## 核心原则

1. **没事不打扰**：日常小负面我直接处理，事后归档
2. **有事必上报**：黄色以上级别立刻通知，附建议方案
3. **处理有记录**：每一次舆情都记录在案，形成案例库
4. **速度优先**：第一时间响应，态度比事实重要

---

## 响应时效总览

| 级别 | 上报时限（报给先生） | 首响时限（口径给出，KB 定稿） | 决策人 |
|------|---------|--------|--------|
| 蓝色（一般） | 无需上报 | 工作日内汇总 | 风谣观察 |
| 黄色（重要） | 即时上报 | 2h 内首响口径 | 风谣主责，先生拍板 |
| 橙色（紧急） | 15min 内 | 1h 内首响 | 风谣拟稿+先生知会 |
| 红色（重大） | 5min 内 | 30min 内首响 | 先生终审口径（正将终审） |

> 时限为内部操作建议，非对外 SLA 承诺。升级原则：事实不清先升一级控场，查清可降级。
