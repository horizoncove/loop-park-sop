# 03-常见场景预案

> **版本：** V1.0
> **用途：** 常见舆情场景的标准应对方案，遇到直接套用

---

## 场景一：价格争议

**典型问题：**
- "宝藏星球的东西比淘宝贵"
- "餐饮比外面贵好多"
- "活动门票不值这个价"

**应对策略：**
1. **不硬杠**：不说"我们不贵"，而是说"我们的价值是什么"
2. **强调体验**：强调场景、服务、活动价值，不只是卖商品
3. **引导对比**：拿同类商圈比，不拿网购比
4. **给解决方案**：发优惠券/会员权益，降低门槛

**参考话术：**
> 理解你的感受～宝藏星球选品的时候确实考虑了性价比，而且我们有校内合伙人送货上门，还有每周活动可以参与，整体算下来还是很划算的～下次来可以看看XX款，性价比超高！

**内部动作：**
- 统计用户吐槽最多的品类
- 调整定价或增加促销
- 增加"性价比推荐"专区

## 场景二：卫生问题

**典型问题：**
- "厕所好脏"
- "垃圾没人清"
- "餐饮不卫生/吃坏肚子"

**应对策略：**
1. **第一时间道歉**：不解释，先认错
2. **立刻整改**：现场马上处理
3. **公开回应**：不仅回复投诉人，还要公开说我们改了
4. **后续跟踪**：三天后回头看，有没有改进

**参考话术：**
> 实在抱歉！这是我们的问题，已经马上安排保洁去清理了，以后我们会增加打扫频次，谢谢你提醒我们！下次来如果还有问题直接找现场工作人员，马上解决～

**内部动作：**
- 增加保洁频次
- 卫生间贴反馈二维码
- 每周卫生检查打卡

## 场景三：排队太久

**典型问题：**
- "活动人太多了挤爆了"
- "排队半小时还没进去"
- "领个券也要排这么久"

**应对策略：**
1. **感谢热情**：先感谢大家的热情，不要嫌人多
2. **给分流方案**：告诉大家错峰时间/替代方案
3. **给福利**：排队久了给点小补偿
4. **提前预告**：以后活动提前说"预计人多，建议错峰"

**参考话术：**
> 谢谢大家这么热情！今天人确实有点多，不好意思让大家久等了😣 下午4点后人会少一些，可以错峰来～排队的同学找工作人员领个小礼品，辛苦啦！

**内部动作：**
- 活动前做人数预估
- 增加分流通道
- 排队区做互动/小游戏

## 场景四：摊主/商户纠纷

**典型问题：**
- 摊主吐槽管理问题
- 商户说流量少
- 摊主之间有矛盾

**应对策略：**
1. **内部解决**：不对外公开细节
2. **统一口径**：对外说"我们在沟通解决"
3. **私下沟通**：跟涉事双方单独聊
4. **不站队**：保持中立，按规则处理

**对外参考话术：**
> 谢谢你的反馈，我们已经在跟摊主沟通啦，会尽快处理好的～

**内部动作：**
- 八将议事讨论
- 按合同规则处理
- 复盘招商/管理有没有问题

## 场景五：安全事故

**典型问题：**
- 顾客摔倒受伤
- 打架斗殴
- 消防/用电问题
- 食品安全问题

**应对策略：**
1. **第一时间救人**：先处理人，再处理舆情
2. **报警/就医**：该走流程走流程
3. **统一对外口径**：只有项目负责人能对外说话
4. **不隐瞒**：事实是什么就说什么，不撒谎
5. **善后跟进**：事后持续跟进受害者情况

**对外参考话术：**
> 非常抱歉发生了这样的事情，我们第一时间送XX去了医院，目前情况XX。我们会全力配合处理，承担相应责任。后续进展会及时告知大家。

**内部动作：**
- 立即启动应急预案
- 项目负责人牵头
- 法律介入
- 全面排查安全隐患

## 场景六：谣言/不实信息

**典型问题：**
- "LOOP PARK要倒闭了"
- "某店食品安全有问题"
- "活动取消是假的"

**应对策略：**
1. **快速澄清**：第一时间发官方说明
2. **拿证据**：用事实说话，不放空炮
3. **@传播者**：私聊传播者，请其删除或更正
4. **不激化**：不骂造谣者，就事论事

**对外参考话术：**
> 关于最近大家关心的XX问题，这里统一说明一下：实际情况是XXX，大家不要轻信不实信息哦～有问题随时找官方号核实！

**内部动作：**
- 官方号发澄清声明
- 社群/朋友圈同步
- 追踪谣言源头
- 必要时发律师函
