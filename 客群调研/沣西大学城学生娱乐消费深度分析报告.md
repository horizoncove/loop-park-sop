## 三、学生娱乐消费画像

### 3.1 消费能力
| 娱乐类型 | 单次消费 | 月均次数 |
|----------|----------|----------|
| 台球 | 15-30元 | 2-3次 |
| 酒吧小聚 | 40-60元 | 1-2次 |
| 棋牌室通宵 | 80-120元 | 1次 |
| KTV（去西安） | 100-150元 | 每月1次 |
| 夜市小吃 | 15-25元 | 每周3-4次 |

### 3.2 时间习惯
- **周一到周四**：下晚自习21:30后出来，玩1-2小时回去
- **周五晚上**：聚会高峰，玩到12点以后
- **周六全天**：白天逛街，晚上娱乐
- **周日下午**：返校，基本不出来
- **考试周**：基本不出来，只买夜宵

### 3.3 决策因素
1. **价格便宜** — 学生生活费有限，人均超过50就觉得贵
2. **离得近** — 超过1.5km就懒得走
3. **关门晚** — 11点前关门等于没有
4. **环境好** — 要适合拍照、适合发朋友圈
5. **有新鲜东西** — 不能跟食堂/周边一样，要有新鲜感

## 五、结论与建议

### 5.1 核心结论
1. **沣西大学城娱乐供给严重不足** — 4万学生，周边娱乐业态少、关门早、环境差
2. **KTV是最大空白** — 学生刚需，但周边一家正规KTV都没有
3. **深夜经济是蓝海** — 周边11点全关门，学生下晚自习后无地方可去
4. **不要打价格战** — 台球厅已经9.9元3小时了，我们拼环境和体验
5. **学生要的是"便宜+近+晚+好玩"** — 四个要素占齐就能赢

### 5.2 下一步行动
1. 先上**学生KTV**（填补空白，最快见效）
2. 同步开**深夜小酒馆+夜宵**（11点后独家生意）
3. 台球做升级（不打价格战，做潮酷+比赛）
4. 自助棋牌做年轻版（加桌游+switch，吸引女生）
5. 所有业态统一比周边便宜20%，晚关门2小时
