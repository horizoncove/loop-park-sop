## 7.1 产品定位与定价

### 7.1.1 产品是什么？

**9#公寓酒店双人间，改造成学生公寓。**

| 配置 | 详情 |
|------|------|
| 户型 | 双人间 |
| 面积 | 38㎡ |
| 配套 | 独立卫浴、空调、WiFi、书桌 |
| 位置 | 4# Loop Chill楼栋 |

### 7.1.2 定价策略

| 时段 | 价格 | 包含 |
|------|------|------|
| 学期中 | 1500元/月/间 | 包水电网（每人100度电+3吨水额度） |
| 开业优惠 | 前3个月1200元/月 | 同上 |
| 寒暑假 | 800元/月保管费 | 房间保留+开学前深度保洁1次 |

### 7.1.3 对比学校宿舍

| 对比项 | 学校四人间 | LOOP PARK双人间 |
|--------|-----------|----------------|
| 价格 | 4200元/年 = 350元/月 | 1500元/月 |
| 人数 | 4-8人一间 | 2人一间 |
| 卫浴 | 公共 | 独立 |
| 空调 | 有，电费自己掏 | 有，包在房租里 |
| 网络 | 自己办 | 包在房租里 |
| 实际月成本 | ~465元/人 | 750元/人 |

> 差价285元/人/月，换更好的隐私和独立卫浴，对家庭条件好的学生来说很合理。

## 7.2 水电网管理规则

### 7.2.1 基础额度

**每人每月免费额度：**
- 电：100度
- 水：3吨
- 网：100M宽带，全包

### 7.2.2 超了怎么办？

- 超出部分按民用价格收：电0.55元/度，水3.5元/吨
- 每月查表，账单发群里
- 透明公开，不赚差价

### 7.2.3 怎么控制浪费？

| 措施 | 怎么做 |
|------|--------|
| 智能电表 | 手机上能查每天用了多少电 |
| 正向激励 | 每月用最少的房间，退50块电费 |
| 提醒 | 快超额度的时候，微信提醒 |

---

## 7.3 寒暑假方案

### 7.3.1 为什么做寒暑假保管？

**学生放假回家，东西不想往回拿，房间空着也是空着。**

收800元/月保管费，比空着强。

### 7.3.2 方案内容

| 项目 | 包含 |
|------|------|
| 价格 | 800元/月 |
| 包含 | 房间保留、东西不动、安全看管 |
| 开学前 | 深度保洁1次，开学直接住 |

### 7.3.3 优势

- **全年12个月都有收入**，没有空房期
- 学生不用搬来搬去，省事
- 我们也多一份收入

## 7.5 获客与转化SOP

### 7.5.1 获客渠道

| 渠道 | 方式 | 成本 |
|------|------|------|
| KOL/KOC CPS | 按成交付费 | 450元/个租客 |
| 校园代理 | 学生介绍，提成 | 500元/个租客 |
| 抖音/小红书 | 发内容引流 | 内容成本 |
| 线下传单 | 学校门口发 | 印刷+人工 |

### 7.5.2 转化流程

```
看到内容 → 加微信 → 发户型图和价格 → 约看房 → 现场看房 → 签合同 → 入住
```

**转化率目标：**
- 加微信 → 约看房：30%
- 看房 → 签合同：50%

## 7.6 客户留存与续约

### 7.6.1 怎么让学生续租？

| 措施 | 怎么做 |
|------|--------|
| 老客优惠 | 续租减100元/月 |
| 社群运营 | 建租客群，平时多互动 |
| 增值服务 | 保洁、电脑租赁，用习惯了就不想走 |
| 活动联动 | 夜市、市集活动，租客有优惠 |

### 7.6.2 退租流程

- 提前15天说
- 退房检查，没有损坏退押金
- 打扫干净，准备下一个租客

**本章小结：**
学生公寓核心是：
- 产品：38㎡双人间，独立卫浴，1500元/月包水电网
- 寒暑假：800元/月保管费，全年不空房
- 增值服务：保洁+电脑租赁，多一份收入
- 获客：纯CPS按效果付费，没效果不花钱
