# 第八章：创业市集与夜市运营专项

> **本章定位：** 市集和夜市是LOOP PARK的**流量发动机**，属于P0级自营业态。
> 本章写透：怎么招摊主、怎么排活动、怎么管品控、怎么赚钱、怎么控风险。

---

## 8.1 市集定位与目标客群

### 8.1.1 为什么市集是P0？

**三个理由：**
1. **引流能力最强** — 夜市是学生周末必去的地方，自带流量
2. **年轻人最爱** — 摆摊、逛市集、淘小玩意，是大学生社交场景
3. **轻资产试错** — 不用自己进货、自己管员工，收摊位费+抽成就行

**一句话定位：** 沣西大学城最火的大学生创业市集。

### 8.1.2 市集分两类

| 类型 | 时间 | 目标客群 | 收入模式 |
|------|------|---------|---------|
| **周末创业市集** | 周六周日白天 | 逛玩+买小东西+拍照打卡 | 摊位费 |
| **夜间经济市集** | 每天晚上18:00-23:00 | 吃夜宵+朋友聚会 | 摊位费+抽成 |

## 8.2 摊位规划与招商

### 8.2.1 摊位数量与类型

**总摊位：60个**

| 类型 | 数量 | 占比 | 摊位费（月） |
|------|------|------|-------------|
| 餐饮小吃类 | 25个 | 42% | 800元/月 + 10%抽成 |
| 文创手作类 | 15个 | 25% | 500元/月 |
| 游戏体验类 | 10个 | 17% | 600元/月 |
| 快闪零售类 | 10个 | 16% | 按次收费100元/天 |

### 8.2.2 招商对象

**优先招这几类摊主：**

| 优先级 | 摊主类型 | 为什么招 |
|--------|---------|---------|
| P0 | **本校大学生创业** | 自带同学流量，故事性强，好宣传 |
| P0 | **网红小吃店** | 自带粉丝，是市集的引流招牌 |
| P1 | **本地手作艺人** | 有独特性，别人抄不走 |
| P1 | **潮玩/文创品牌快闪** | 提升市集档次 |
| P2 | **普通摊主** | 补充品类 |

### 8.2.3 招商流程

```
报名 → 选品审核 → 试摆1天 → 正式入驻 → 月度考核
```

1. **报名：** 线上表单+线下报名点
2. **选品审核：** 不能跟现有摊位重复（同一品类最多3家）
3. **试摆：** 免费试摆1天，看人流和销量
4. **正式入驻：** 签合同，交押金
5. **月度考核：** 连续2个月销量倒数10%的淘汰

## 8.3 摊主管理与培训

### 8.3.1 摊主准入条件

**必须满足：**
- 有正经货品，不是卖三无产品
- 身体健康，有健康证（餐饮类必须）
- 同意市集统一管理规则
- 服从统一营业时间安排

### 8.3.2 摊主培训（新摊主必做）

**新摊主入驻前，半天培训：**

| 培训内容 | 时长 | 谁来讲 |
|---------|------|--------|
| 市集规则与营业时间 | 30分钟 | 运营 |
| 线上运营（怎么发抖音/小红书） | 1小时 | 内容主管 |
| 出餐效率与品控（餐饮类） | 1小时 | 运营主管 |
| 收银与收款码设置 | 30分钟 | 财务 |

### 8.3.3 摊主考核与淘汰

**每月考核指标：**
| 指标 | 权重 | 淘汰线 |
|------|------|--------|
| 月销售额 | 40% | 低于同品类后10% |
| 好评率 | 30% | 低于90% |
| 出勤率 | 20% | 无故缺席3次以上 |
| 配合度 | 10% | 不服从管理3次以上 |

> 连续2个月不达标，直接清退，把位置让给新摊主。

## 8.6 供应链与品控

### 8.6.1 餐饮品控标准

**所有餐饮摊主必须做到：**
1. 食材新鲜，当天采购
2. 摊主必须戴口罩、手套
3. 餐具必须一次性或消毒
4. 价格明码标价
5. 不能卖三无食品

**抽查机制：**
- 每周随机抽查5家餐饮摊
- 发现问题第一次警告，第二次罚款200元，第三次清退

### 8.6.2 统一供应链（后期做）

**前期先不管供应链，让摊主自己进货。**

**等市集做起来之后，我们可以做：**
- 统一集中采购食材，降低摊主成本
- 我们赚供应链差价
- 同时更好控制品质

> 这个是第二阶段的事，先把人流做起来再说。

## 8.7 收入模型与盈亏平衡

### 8.7.1 收入来源

| 收入项 | 月收入估算 | 备注 |
|--------|-----------|------|
| 摊位费（固定60个） | 60 × 平均650元 = 39000元 | 基础收入 |
| 餐饮抽成（10%） | 25摊 × 日均1500元 × 30天 × 10% = 11250元 | 浮动收入 |
| 快闪摊位费 | 100元/天 × 10天 = 1000元 | 补充收入 |
| 活动报名费 | 不定 | 额外收入 |
| **合计月收入** | **~51000元** | |

### 8.7.2 成本结构

| 成本项 | 月成本 |
|--------|--------|
| 保洁人员（3人） | 9000元 |
| 安保人员（2人） | 6000元 |
| 电费+水费 | 5000元 |
| 活动物料+宣传 | 8000元 |
| 运营人员（2人） | 12000元 |
| **合计月成本** | **40000元** |

### 8.7.3 盈亏平衡

- **月利润：** 51000 - 40000 = **11000元/月**
- **年利润：** ~13万
- **前期投入：** 场地装修+水电改造 ≈ 20万
- **回本周期：** ~18个月

> 市集本身不是赚大钱的，它是**引流工具**——把学生吸引过来，消费宝藏星球、餐饮、公寓这些其他业态。

## 8.8 风险控制与应急预案

### 8.8.1 常见风险与应对

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|---------|
| 天气不好（下雨） | 高 | 人流骤降 | 搭雨棚，雨天改线上活动 |
| 食品安全问题 | 中 | 品牌受损 | 严格抽查，买公众责任险 |
| 摊主跑路 | 低 | 临时空摊 | 收押金，备用摊主名单 |
| 噪音投诉 | 中 | 被城管查 | 控制音量，22:30必须停 |
| 治安问题 | 低 | 安全事故 | 配安保，装监控 |
| 城管检查 | 中 | 临时停业 | 所有证件办齐，提前沟通 |

### 8.8.2 应急预案

**应急预案1：食品安全事件**
1. 马上带顾客去医院
2. 封存问题食品
3. 通知监管部门
4. 24小时内出公告

**应急预案2：下雨天气**
1. 提前看天气预报
2. 搭临时雨棚
3. 当天摊主减免摊位费
4. 改期或取消活动

**应急预案3：顾客投诉**
1. 运营人员5分钟内到现场
2. 能现场解决的马上解决
3. 解决不了的找主管
4. 24小时内给回复

**本章小结：**
市集和夜市是LOOP PARK的流量发动机，60个摊位，月收入5万，成本4万，月利润1万。
