## 9.5 风险识别与应对

### 9.5.1 十大风险

| 风险 | 概率 | 影响 | 应对方案 |
|------|------|------|---------|
| 招商不及预期 | 高 | 入驻率低，没流量 | 先自营撑住，慢慢招商 |
| 学生消费力不足 | 中 | 客单价低 | 多做低价高频产品 |
| 同质化竞争 | 中 | 跟旁边商圈抢客户 | 做活动做IP，差异化 |
| 食品安全 | 低 | 品牌受损 | 严格品控，买保险 |
| 消防安全 | 低 | 安全事故 | 每月检查，配消防器材 |
| 政策监管 | 中 | 城管/消防查 | 证件办齐，提前沟通 |
| 运营成本超支 | 高 | 利润变薄 | 严格预算控制 |
| 人流不及预期 | 高 | 所有业态都受影响 | 加大活动投入，引流 |
| 商户跑路 | 低 | 临时空铺 | 收押金，备用商户名单 |
| 舆情负面 | 中 | 品牌受损 | 舆情监测，及时回应 |

### 9.6.1 核心KPI

| 指标 | 目标值 | 监控频率 |
|------|--------|---------|
| 日均客流 | 3000人 | 每日 |
| 周末客流 | 8000人 | 每周 |
| 入驻率 | 60%（首年） | 每月 |

| 学生公寓入住率 | 80% | 每月 |
| 活动场均人数 | 200人 | 每场活动后 |
| 月营收 | 40万 | 每月 |

### 9.6.2 数据看板

**每月必看：**
1. 客流趋势（周环比、月环比）
2. 各业态营收占比
3. 商户满意度
4. 学生公寓入住率和续约率
5. 营销ROI

**本章小结：**
LOOP PARK总投资400万，稳态运营后年收入500万，年利润100万，4年回本。
核心风险是人流和招商，应对方法是先自营撑住引流，慢慢招商。
关键指标：日均客流、入驻率、学生公寓入住率、活动人数。
