# 第三章：组织架构与人力

> LOOP PARK的组织模型叫"千门八将"。
> 八将不是八个固定职位，是八种做事的角色和思维方式。
> 一个人可以兼多个将，一个将也可以由多人承担。

---

## 3.1 千门八将组织模型

### 3.1.1 八将角色定义

| 将 | 角色定位 | LOOP PARK对应 | 核心职责 | 思维方式 |
|----|---------|--------------|---------|---------|
| **正将** | 外联+招商 | 项目负责人 | 政府、学校、招商、金融融资 | 对外，搞资源 |
| **反将** | 造星计划负责人 | 明线KOL运营 | Season Face、网红打卡、引流 | 对人，搞流量 |
| **脱将** | 3#7#运营+商户服务 | 运营总管 | 楼栋运营、商户服务、财务出纳 | 对内，搞运营 |
| **风将** | OPC/星探 | 摄影师管理 | 网红路线、拍照打卡、摄影师合作 | 对眼，搞曝光 |
| **火将** | 安保+工程+维修 | 安保主管 | 安保、工程、消防、派出所对接 | 对事，搞安全 |
| **除将** | 审计+合规 | 独立审计 | 财务复核、合规审查、风险控制 | 对账，搞监督 |
| **谣将** | 内容主管 | 新媒体运营 | 短视频、社群、内容分发 | 对嘴，搞传播 |
| **提将** | 财务会计 | 与正将兼任 | 会计、对账、预算 | 对钱，搞核算 |

## 3.3 议事规则

### 3.3.1 核心原则

八将议事不是开会投票，是按角色分工推进。

### 3.3.2 议事流程

```
正将发起 → 八将各自表态 → 红蓝对抗 → 正将拍板 → 脱将执行 → 除将监督 → 谣将传播 → 提将核算
```

1. **正将发起** → 提出议题和目标
2. **八将各自表态** → 从自己的角色角度分析可行性
3. **红蓝对抗** → 至少一轮质疑和回应
4. **正将拍板** → 正将有最终决策权（但需听取除将的风险提示）
5. **脱将执行** → 脱将负责落地和协调
6. **除将监督** → 除将全程监督合规和财务
7. **谣将传播** → 谣将负责对外传播
8. **提将核算** → 提将负责成本和收益核算

### 3.3.3 议事频率

| 会议 | 频率 | 参加人 | 内容 |
|------|------|--------|------|
| 周会 | 每周一 | 八将全员 | 复盘上周+计划本周 |
| 月会 | 每月初 | 八将全员+实控人 | 月度复盘+战略调整 |
| 专题会 | 按需 | 相关将参加 | 不要求全员 |

## 3.5 八将日常工作（一周）

### 3.5.1 正将（项目负责人）
- 周一：周会，定本周重点
- 周二-周三：跑政府、跑学校、见招商客户
- 周四：跟商户吃饭，维护关系
- 周五：复盘本周，安排下周

### 3.5.2 脱将（运营总管）
- 每天：巡场，检查商户、检查卫生、处理投诉
- 每周：跟所有商户聊一遍，了解经营情况
- 每月：出运营月报

### 3.5.3 反将（造星计划）
- 每周：筛新人，找新的网红苗子
- 每月：办一次Season Face评选
- 活动：大型活动时负责KOL接待和对接

### 3.5.4 谣将（内容主管）
- 每天：发1条抖音/小红书
- 每周：拍3条短视频
- 每月：做1个内容数据复盘

### 3.5.5 火将（安保工程）
- 每天：巡检消防、用电、设备
- 每周：检查一遍监控
- 每月：做一次消防演练

### 3.5.6 风将（OPC/星探）
- 每天：在打卡点拍照，发素材
- 每周：对接3个摄影师
- 每月：更新网红打卡路线

### 3.5.7 提将（财务）
- 每天：收款、记账
- 每周：出收支周报
- 每月：出财务月报，做下月预算

### 3.5.8 除将（审计合规）
- 每月：审计一次账目
- 每季度：做一次合规检查
- 随时：接举报，查问题
